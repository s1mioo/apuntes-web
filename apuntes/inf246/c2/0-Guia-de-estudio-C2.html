Guía armada el viernes 23 de octubre con las láminas LinearMemory y VirtualMemory, el Certamen 2 de 2023-1 y las preguntas de memoria de los certámenes 2014, 2015 y 2016. Mismo esquema que la del C1: una página por tema y una de ejercicios por pregunta.

En la sala

Los primeros 3 minutos: escribe en una esquina de la hoja la chuleta de abajo. El tiempo: 70 minutos para 105 puntos son unos 40 segundos por punto; una pregunta de 5 puntos no debería tomarte más de 4 minutos. El orden: empieza por la parte que te resulte más fácil; si una pregunta se traba, sáltala y vuelve.

Cómo contestar las preguntas de conocimiento: definición, mecanismo y consecuencia, en 3 a 6 líneas. Usa los nombres de las láminas (MMU, BASE, LÍMITE, TRAP, swap-in, swap-out, page fault, bit V, U, D). En los ejercicios, escribe siempre el cálculo intermedio (la división de b, el div y el mod).

Chuleta

LINEAL      @física = BASE + d      si d < LÍMITE (si no, TRAP) · modo sistema: acceso directo
BLOQUES     b = ⌈K / bloque⌉        frag. interna = b × bloque − K
FIT         FIRST: la 1.ª donde cabe · BEST: menor remanente · WORST: mayor remanente
            actualizar: (Start + b, Size − b), o borrar la fila si queda en 0
BITS        m = (RAM / bloque) / 8 bytes          4 GB con 8 KB → 64 KB
LISTA       primer bloque de cada zona libre: n / s (bloques libres / próxima zona)
COMPACTAR   t = 2 × t_acceso × bytes              50 ns → 105 ms/MB ≈ 107 s/GB
SEGMENTOS   @(s, d) → BASE_s + d, d < LÍMITE_s · S bits de segmento + (64 − S) de offset
PÁGINAS     pág = d div 2^K · off = d mod 2^K · @ = marco × 2^K + off
SEG. PAG.   i = offset div 2^K · o = offset mod 2^K · @ = marco(i) × 2^K + o
V U D       V: presente (0 → page fault) · U: usada · D: escrita
            el SO pone U = D = 0 al cargar; la MMU los pone en 1 · D = 1 exige U = 1 y W = 1
ERRORES     no existe → memory/segmentation violation · fuera del límite → segmentation violation
            V = 0 → page/segment fault (se recupera) · RWX → permission denied
TLB         asociativa, ≈ 1 ns, cache con LRU · HIT: marco directo · MISS: tabla indexada
TABLAS      indexada: 2^(bits de página) entradas por proceso · invertida: RAM / página, una sola
            jerárquica (X, Y, Z, offset): primaria siempre cargada · table fault

Repaso relámpago

  1. La MMU traduce y controla en cada acceso; por eso es hardware.
  2. Lineal: @física = BASE + d, con d < LÍMITE; el SO carga BASE y LÍMITE en cada conmutación.
  3. Interna = sobra adentro de lo asignado. Externa = libre afuera, en pedazos inútiles.
  4. Particiones fijas: no se conoce el tamaño de los procesos a priori → las dos fragmentaciones.
  5. b = ⌈K / bloque⌉. FIRST la primera, BEST el menor remanente, WORST el mayor.
  6. El arreglo de bits gasta memoria; la lista “n / s” vive en los bloques libres.
  7. Compactar: 2 × 50 ns × bytes; teóricamente posible, impracticable con GB.
  8. Swapping: caro (disco un millón de veces más lento); útil solo con otro proceso listo y con DMA.
  9. Memoria virtual: transparencia de ubicación y protección.
  10. Segmento = BASE + LÍMITE; tabla global (V, BASE, LÍMITE, U, D) y tabla por proceso (RWX).
  11. U y D: el SO los pone en 0 al cargar, la MMU en 1. U = 0 buen candidato; D = 1 hay que escribirlo.
  12. Paginación: marcos de 2K, sin fragmentación externa, page fault cuando V = 0.
  13. Páginas chicas: menos fragmentación, tablas grandes. Grandes: al revés.
  14. TLB: cache asociativa de descriptores con LRU; jerárquica para espacios enormes; invertida, una por sistema.
  15. Segmentación paginada: segmento → su tabla de páginas → marco. Violation si el segmento no existe o el offset se sale.

Errores típicos

ErrorLo correcto
Decir que la fragmentación interna es “la de la memoria” y la externa “la de los procesos”Interna: sobra dentro de lo asignado. Externa: zonas libres demasiado chicas entre asignaciones.
150 / 16 = 9,375 → 9 bloquesSi no es exacto se suma 1: 10 bloques.
BEST FIT = la zona más chicaLa zona más chica donde cabe: el menor remanente ≥ 0.
Olvidar actualizar la tabla después de asignar(Start + b, Size − b), o borrar la fila.
d ≤ LÍMITEd < LÍMITE. Con LÍMITE = 1000, la última dirección válida es 999.
Olvidar el 2 en el costo de compactarCada byte se lee y se escribe: 2 × tacceso.
Llamar “segment fault” a un acceso ilegalSegment fault = no está cargado (se recupera). Ilegal = segmentation violation.
Decir que el SO pone U o D en 1La MMU los pone en 1; el SO los pone en 0 al cargar.
“La paginación no tiene fragmentación”No tiene externa; la interna queda en la última página.
Decir que la TLB guarda toda la tablaGuarda unas pocas entradas, las más recientes (LRU).
Indexar la tabla invertida por páginaSe indexa por marco; se busca el par (PID, p).
Confundir R (Refer) con R (Read)Refer es un bit de uso reciente que se borra cada TICK; Read es un derecho.
Decir que el page fault es un error del programaEs el funcionamiento normal de la paginación bajo demanda.
Usar 1 KB = 1000 BEn las láminas, 1 KB = 1024 B y 1 GB = 1024³ B.

Glosario

TérminoQué es
MMUMemory Management Unit: hardware del procesador que traduce y verifica cada dirección.
Dirección lógica / virtualLa que ve el programa. Física: la que entra al chip de memoria.
BASE / LÍMITEDónde empieza la zona del proceso y cuánto mide.
BloqueUnidad de asignación de tamaño fijo en particiones dinámicas.
RemanenteLo que sobra de una zona libre después de asignar: Size − b.
Swap-in / swap-outCargar desde / descargar hacia la zona de swap del disco.
DMADirect Memory Access: transferencias sin ocupar la CPU.
Dynamic linkerResuelve las direcciones de las bibliotecas y de un programa reubicado al ejecutar.
OverlayParte del programa que se carga encima de otra cuando hace falta.
SegmentoZona lógica del proceso (código, datos, pila) con BASE y LÍMITE.
Página / marco (frame)Trozo de 2K bytes del espacio virtual / de la RAM.
V, U, D, R, COWValid (presente), Used (usada), Dirty (escrita), Refer (uso reciente), Copy On Write.
Page fault / segment faultAcceso a algo válido pero no cargado: se carga y se sigue.
Memory violation / segmentation violationAcceso a algo que no existe o fuera del límite: error del proceso.
Permission deniedLa operación no está permitida por los derechos R, W, X.
On demand pagingCargar cada página solo cuando se la necesita (al ocurrir el page fault).
Thrashing (hiperpaginación)Page faults continuos con páginas recién descargadas; el sistema colapsa.
TLBTranslation Lookaside Buffer: memoria asociativa que guarda descriptores recientes.
LRULeast Recently Used: sale lo que se usó hace más tiempo.
Table faultEn la tabla jerárquica, falta una subtabla durante la búsqueda.
Sinon“Si no”, en francés (lámina 27). El profe usa nomenclatura francesa.

Cuando lleguen las ayudantías

En el C1, lo que más se pareció al certamen fueron las ayudantías. Cuando las mandes:

  1. Las resuelvo y reviso sus pautas (en el C1, la de la Ayudantía 3 tenía una errata).
  2. Subo la probabilidad de las secciones que cubren, y lo anoto en cada sección.
  3. Las agrego a la página 5 como el bloque de mayor prioridad, y reajusto el plan.

Si tienes grabaciones de las clases de memoria, mándalas también: en el C1 los audios mostraron cosas que no estaban en las láminas (como lo que el profe excluyó). Y si encuentras la lámina de reemplazo de páginas, la página 4 deja de estar “por confirmar”.
