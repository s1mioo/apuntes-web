Durante el certamen

Son 5 horas para 2 problemas. El tiempo alcanza; lo que se pierde es por elegir mal o quedarse pegado.

  • Primeros 20 minutos: leer los 5. Por cada uno anota el tamaño de n, qué pregunta (máximo, mínimo, cuántas formas, existe) y la técnica según las tablas de arriba.
  • Elige los 2 que tengan plantilla directa. En 2026-1 eran C (Bellman-Ford), D (alineamiento) y E (scheduling), que salen casi tal cual. A era un truco de una línea si se veía la paridad.
  • Antes de escribir: calcula las operaciones (n × trabajo), decide int o long long, y piensa en el caso más chico (n = 1, grafo sin aristas, un solo tipo).
  • Copia la plantilla y adapta la lectura. Compila, pega los ejemplos, compara carácter a carácter.
  • Si da respuesta incorrecta: revisa la lista de errores. Después haz un caso chico a mano o una fuerza bruta de 15 líneas y compara.
  • Si un ejemplo contradice al enunciado: relee, y pregunta por la vía de aclaraciones del juez. Mira la sección de erratas: ya pasó varias veces.
  • Llevas 40 minutos sin avanzar: cambia de problema. La planificación del ramo lo deja como aviso para la sesión de repaso: pasar a otro y no quedarse pegado.

#include <bits/stdc++.h>
using namespace std;

const long long MOD = 1000000007;

/*
 * buscarRespuesta
 * Inputs: lo -> valor que NO cumple; hi -> valor que SI cumple; cumple -> funcion
 *         monotona (false, false, ..., true, true).
 * Return: el menor valor que cumple.
 * Que hace: busqueda binaria sobre la respuesta. O(log(hi - lo)) evaluaciones.
 */
long long buscarRespuesta(long long lo, long long hi, const function<bool(long long)>& cumple){
    while (hi - lo > 1){
        long long medio = lo + (hi - lo) / 2;
        if (cumple(medio)) hi = medio;
        else lo = medio;
    }
    return hi;
}

/*
 * modReal
 * Inputs: x -> entero, puede ser negativo; m -> modulo positivo.
 * Return: el resto en el rango [0, m).
 */
long long modReal(long long x, long long m){
    return ((x % m) + m) % m;
}

/*
 * potenciaMod
 * Inputs: b -> base; e -> exponente >= 0; m -> modulo.
 * Return: b^e mod m. O(log e).
 */
long long potenciaMod(long long b, long long e, long long m){
    long long r = 1 % m;
    b %= m;
    while (e > 0){
        if (e & 1) r = r * b % m;
        b = b * b % m;
        e >>= 1;
    }
    return r;
}

/*
 * pascal
 * Inputs: n -> mayor fila.
 * Return: tabla C donde C[i][j] es "i sobre j" mod MOD. O(n^2).
 */
vector<vector<long long>> pascal(int n){
    vector<vector<long long>> C(n + 1, vector<long long>(n + 1, 0));
    for (int i = 0; i <= n; i++){
        C[i][0] = 1;
        for (int j = 1; j <= i; j++) C[i][j] = (C[i - 1][j - 1] + C[i - 1][j]) % MOD;
    }
    return C;
}

/*
 * ventanaMinimo
 * Inputs: a -> arreglo; k -> largo de la ventana.
 * Return: el minimo de cada ventana de largo k. O(n).
 * Que hace: el deque guarda indices con valores crecientes; un elemento que ya
 *           tiene a la derecha uno menor o igual nunca volvera a ser minimo.
 */
vector<int> ventanaMinimo(const vector<int>& a, int k){
    deque<int> dq;
    vector<int> r;

    for (int i = 0; i < (int)a.size(); i++){
        while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) r.push_back(a[dq.front()]);
    }
    return r;
}

Backtracking y fuerza bruta

Probabilidad: muy alta

Cuándo: el espacio de soluciones cabe (mira la tabla de tamaños) o hay restricciones que permiten podar. El patrón de clases es elegir, verificar, explorar, deshacer.

Lo que cambia de un problema a otro es qué decisiones hay, cuándo una solución está completa, qué restricción cumple y cuándo se poda.

  • Combinaciones (no importa el orden): el ciclo parte en inicio y se llama con i + 1. Así no se repite {1,3} como {3,1}. Costo O(k · C(n,k)).
  • Subconjuntos: cada nodo del árbol ya es solución, o se recorren máscaras de 0 a 2n − 1. Costo O(n · 2n).
  • Permutaciones (importa el orden): no hay inicio, se usa un arreglo usado. Costo O(n · n!).
  • Con elementos repetidos: recorre letras distintas con un contador por letra (T24·D), o usa next_permutation sobre el arreglo ordenado.

Poda: decidir no hacer la llamada recursiva porque esa rama ya no sirve. Hay dos motivos: no puede dar una solución válida, o (en optimización) no puede mejorar la mejor conocida. pop_back no es la poda: solo deshace la elección.

Branch and bound: si costo actual + estimación optimista de lo que falta ya no mejora, se poda. Sigue siendo exacto; el peor caso sigue siendo exponencial.

    }

    for (int i = inicio; i < (int)c.size(); i++){

        actual.push_back(c[i]);
        generar(c, actual, i + 1, k, suma + c[i], S, total);
        actual.pop_back();
    }
}

 *           a[j]. O(n * 2^n), sirve hasta n cercano a 20 - 22.
 */
long long contarConMascara(const vector<int>& a, long long S){
    int n = a.size();
    long long total = 0;

    for (int mascara = 0; mascara < (1 << n); mascara++){
        long long suma = 0;
        for (int j = 0; j < n; j++)
            if (mascara & (1 << j)) suma += a[j];
        if (suma == S) total++;
    }
    return total;

}

Máscaras y PD sobre subconjuntos

Probabilidad: media

Cuándo: n ≤ 20 aproximadamente, importa el orden, y al futuro solo le interesa qué elementos se usaron y cuál fue el último. Eso convierte n! en 2n · n2.

Operaciones con bits: el bit i está encendido si m >> i & 1; se enciende con m | (1 << i); __builtin_popcount(m) cuenta cuántos hay. Las submáscaras se recorren con for (int s = m; s; s = (s - 1) & m).

Se resuelve por máscara creciente, porque agregar un elemento siempre agranda el número. Si necesitas algo más en el estado (categoría del último, resto módulo M), agrégalo como dimensión: mira T25·E y L3·G.

#include <bits/stdc++.h>
using namespace std;

const long long INF = LLONG_MAX / 4;

/*
 * tspBacktracking
 * Inputs: d -> distancias; visitado -> ciudades ya usadas; pos -> ciudad actual;
 *         cuenta -> cuantas van; costo -> costo acumulado; mejor -> mejor tour.
 * Return: nada; actualiza mejor.
 * Que hace: arma el recorrido ciudad por ciudad. Poda: con distancias positivas,
 *           si costo >= mejor esa rama no puede mejorar. O(n!) en el peor caso.
 */
void tspBacktracking(const vector<vector<long long>>& d, vector<bool>& visitado, int pos, int cuenta,
                     long long costo, long long& mejor){
    int n = d.size();
    if (costo >= mejor) return;

    if (cuenta == n){
        mejor = min(mejor, costo + d[pos][0]);
        return;
    }

    for (int i = 0; i < n; i++){
        if (visitado[i]) continue;
        visitado[i] = true;
        tspBacktracking(d, visitado, i, cuenta + 1, costo + d[pos][i], mejor);
        visitado[i] = false;
    }
}

/*
 * tspMascara
 * Inputs: d -> distancias.
 * Return: costo minimo de salir de 0, visitar todas una vez y volver a 0.
 * Que hace: dp[mascara][v] es el costo minimo de partir en 0, visitar exactamente
 *           las ciudades de mascara y terminar en v. Al futuro solo le importa
 *           que ciudades se usaron y donde estoy, no el orden. O(2^n * n^2).
 */
long long tspMascara(const vector<vector<long long>>& d){
    int n = d.size();
    int total = 1 << n;
    vector<vector<long long>> dp(total, vector<long long>(n, INF));
    dp[1][0] = 0;

    for (int mascara = 1; mascara < total; mascara += 2){
        for (int v = 0; v < n; v++){
            if (dp[mascara][v] == INF) continue;
            for (int w = 0; w < n; w++){
                if (mascara >> w & 1) continue;
                int nueva = mascara | (1 << w);
                dp[nueva][w] = min(dp[nueva][w], dp[mascara][v] + d[v][w]);
            }
        }
    }

    if (n == 1) return 0;
    long long mejor = INF;
    for (int v = 1; v < n; v++)
        mejor = min(mejor, dp[total - 1][v] + d[v][0]);
    return mejor;
}

Algoritmos voraces

Probabilidad: muy alta

Cuándo: se puede ordenar los datos de modo que una decisión local nunca estorbe. Decide y no vuelve atrás. Hay que convencerse de que funciona, porque muchas veces no funciona: en MWIS con pesos 1, 4, 5, 4, tomar el mayor da 6 y el óptimo es 8.

Argumento de intercambio (clase 17). Toma una solución óptima distinta de la voraz, encuentra dos elementos adyacentes en el orden equivocado e intercámbialos: el costo no aumenta. Repitiendo se llega a la voraz, así que la voraz también es óptima.

GreedyRatio (clases 16 y 17). Minimizar la suma de wj · Cj en una máquina: ordenar por w/l de mayor a menor. Si i va justo antes que j, intercambiarlos cambia el costo en wi · lj − wj · li, y solo cambian Ci y Cj. Con wi/li < wj/lj ese cambio es negativo, por eso el orden correcto mejora. Si hay empate el costo no cambia.

¿Por qué no ordenar por w − l? Con l = (5, 2) y w = (3, 1), GreedyDiff pone primero al trabajo 2 y da 23. GreedyRatio pone primero al 1 y da 22.

Patrones frecuentes

  • Emparejar dos listas: ordenar ambas y usar dos punteros (L4·A, L4·G).
  • Agrupar: ordenar y cortar cuando se viole la condición (T25·D).
  • La mejor opción va cambiando: heap (L4·B, Huffman).
  • Máxima cantidad de intervalos sin traslape: ordenar por fin.
  • Mochila fraccionaria: ordenar por valor/peso. Ojo: la mochila 0/1 no se resuelve con voraz.
#include <bits/stdc++.h>
using namespace std;

struct Tarea { long long l, w; };

/*
 * costoGreedyRatio
 * Inputs: t -> tareas con largo l y peso w (se ordenan aqui).
 * Return: el minimo de la suma de w_j * C_j.
 * Que hace: mayor w/l primero. La comparacion se hace cruzada para no usar
 *           decimales, y con > estricto porque sort no admite >=. O(n log n).
 */
long long costoGreedyRatio(vector<Tarea>& t){
    sort(t.begin(), t.end(), [](const Tarea& a, const Tarea& b){
        return a.w * b.l > b.w * a.l;
    });

    long long tiempo = 0, costo = 0;
    for (const Tarea& x : t){
        tiempo += x.l;
        costo += x.w * tiempo;
    }
    return costo;
}

/*
 * emparejar
 * Inputs: chicos, grandes -> dos listas (se ordenan aqui).
 * Return: cuantas parejas se forman con chicos[i] <= grandes[j], usando cada
 *         elemento a lo mas una vez.
 * Que hace: recorre grandes de menor a mayor y le da a cada uno el chico mas
 *           chico que quede, si cabe. O(n log n + m log m).
 */
int emparejar(vector<int>& chicos, vector<int>& grandes){
    sort(chicos.begin(), chicos.end());
    sort(grandes.begin(), grandes.end());

    int hechas = 0;
    for (int j = 0; j < (int)grandes.size() && hechas < (int)chicos.size(); j++)
        if (chicos[hechas] <= grandes[j]) hechas++;
    return hechas;
}

/*
 * intervalosDisjuntos
 * Inputs: v -> intervalos (inicio, fin) (se ordenan aqui).
 * Return: la mayor cantidad de intervalos sin traslape.
 * Que hace: ordena por fin y toma cada uno que parta despues del ultimo elegido.
 *           Terminar lo antes posible deja el mayor espacio libre. O(n log n).
 */
int intervalosDisjuntos(vector<pair<int, int>>& v){
    sort(v.begin(), v.end(), [](const pair<int, int>& a, const pair<int, int>& b){
        return a.second < b.second;
    });

    int total = 0, ultimoFin = INT_MIN;
    for (const auto& x : v){
        if (x.first > ultimoFin){
            total++;
            ultimoFin = x.second;
        }
    }
    return total;
}

Huffman

Probabilidad: media

Cuándo: código binario libre de prefijo de largo promedio mínimo, o cualquier proceso que fusiona de a dos con costo igual a la suma (unir cuerdas, archivos, etc.).

Idea. El código es un árbol con los símbolos en las hojas, y el largo de un símbolo es su profundidad. Al fusionar dos árboles, todas sus hojas bajan un nivel, así que el costo sube exactamente en P(T1) + P(T2). Por eso conviene fusionar los dos de menor peso. Se hacen n − 1 fusiones, y con min-heap el costo es O(n log n).

El costo total es la suma de todas las fusiones, sin armar el árbol. Si piden los códigos, se usa la segunda función.

#include <bits/stdc++.h>
using namespace std;

/*
 * costoHuffman
 * Inputs: p -> frecuencia de cada simbolo.
 * Return: suma de p_a * largo(a) del codigo optimo.
 * Que hace: min-heap de pesos. En cada fusion todas las hojas de ambos arboles
 *           bajan un nivel, asi que el costo sube justo en a + b. O(n log n).
 */
long long costoHuffman(const vector<long long>& p){
    priority_queue<long long, vector<long long>, greater<long long>> h(p.begin(), p.end());
    long long total = 0;

    while (h.size() > 1){
        long long a = h.top(); h.pop();
        long long b = h.top(); h.pop();
        total += a + b;
        h.push(a + b);
    }
    return total;
}

/*
 * asignar
 * Inputs: izq, der -> hijos de cada nodo (-1 si es hoja); v -> nodo actual;
 *         prefijo -> bits del camino; codigos -> salida indexada por hoja.
 * Return: nada; escribe el codigo de cada hoja del subarbol de v.
 */
void asignar(const vector<int>& izq, const vector<int>& der, int v, const string& prefijo, vector<string>& codigos){
    if (izq[v] == -1){
        codigos[v] = prefijo.empty() ? "0" : prefijo;
        return;
    }
    asignar(izq, der, izq[v], prefijo + "0", codigos);
    asignar(izq, der, der[v], prefijo + "1", codigos);
}

/*
 * construirCodigos
 * Inputs: p -> frecuencia de cada simbolo.
 * Return: el codigo binario de cada simbolo.
 * Que hace: igual que costoHuffman, pero el heap guarda (peso, nodo) y cada
 *           fusion crea un nodo interno nuevo con sus dos hijos.
 */
vector<string> construirCodigos(const vector<long long>& p){
    int n = p.size();
    vector<int> izq(2 * n, -1), der(2 * n, -1);
    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<pair<long long, int>>> h;

    for (int i = 0; i < n; i++) h.push({p[i], i});

    int siguiente = n;
    while (h.size() > 1){
        auto a = h.top(); h.pop();
        auto b = h.top(); h.pop();
        izq[siguiente] = a.second;
        der[siguiente] = b.second;
        h.push({a.first + b.first, siguiente});
        siguiente++;
    }

    vector<string> codigos(2 * n);
    asignar(izq, der, h.top().second, "", codigos);
    codigos.resize(n);
    return codigos;
}

Árbol de expansión mínima: Kruskal y Prim

Probabilidad: alta

Cuándo: conectar todos los vértices al menor costo sin ciclos. Grafo no dirigido.

  • Kruskal ordena las aristas y acepta las que unen componentes distintas (Union-Find). Es lo más cómodo si la entrada es una lista de aristas. O(m log m).
  • Prim hace crecer un solo árbol por la arista más barata que cruza la frontera. Cómodo con lista de adyacencia. O(m log n).

Variantes: árbol máximo ordenando de mayor a menor (T24·E). Bosque si el grafo no es conexo: Kruskal entrega la suma sin más. Agrupar en k componentes: detente tras n − k uniones. Union-Find solo también sirve para preguntar si dos vértices están conectados.

Con unión por tamaño, buscar cuesta O(log n); sumando compresión de caminos, casi O(1) amortizado.

#include <bits/stdc++.h>
using namespace std;

struct Arista { int u, v; long long c; };

/*
 * buscar
 * Inputs: p -> arreglo de padres; x -> vertice.
 * Return: representante del conjunto de x (comprime el camino).
 */
int buscar(vector<int>& p, int x){
    if (p[x] != x) p[x] = buscar(p, p[x]);
    return p[x];
}

/*
 * unir
 * Inputs: p, tam -> Union-Find; a, b -> vertices.
 * Return: true si estaban en conjuntos distintos y se unieron.
 * Que hace: union por tamano: el arbol chico queda colgando del grande.
 */
bool unir(vector<int>& p, vector<int>& tam, int a, int b){
    a = buscar(p, a);
    b = buscar(p, b);
    if (a == b) return false;
    if (tam[a] < tam[b]) swap(a, b);
    p[b] = a;
    tam[a] += tam[b];
    return true;
}

/*
 * kruskal
 * Inputs: n -> vertices 1..n; aristas -> se ordenan aqui por costo.
 * Return: costo total del bosque de expansion minimo.
 * Que hace: recorre las aristas de menor a mayor y acepta las que no cierran
 *           ciclo. O(m log m).
 */
long long kruskal(int n, vector<Arista>& aristas){
    sort(aristas.begin(), aristas.end(), [](const Arista& a, const Arista& b){ return a.c < b.c; });

    vector<int> p(n + 1), tam(n + 1, 1);
    iota(p.begin(), p.end(), 0);

    long long total = 0;
    for (const Arista& e : aristas)
        if (unir(p, tam, e.u, e.v)) total += e.c;
    return total;
}
#include <bits/stdc++.h>
using namespace std;

typedef pair<long long, int> Par;

/*
 * prim
 * Inputs: n -> vertices 0..n-1; g -> lista de adyacencia con (vecino, costo).
 * Return: costo del arbol de expansion minimo, o -1 si el grafo no es conexo.
 * Que hace: X crece un vertice a la vez, siempre por la arista mas barata que
 *           cruza la frontera. El heap guarda candidatos; cuando sale uno cuyo
 *           vertice ya esta en X se descarta (borrado perezoso). O(m log m).
 */
long long prim(int n, const vector<vector<pair<int, long long>>>& g){
    vector<bool> enX(n, false);
    priority_queue<Par, vector<Par>, greater<Par>> h;
    h.push({0, 0});

    long long total = 0;
    int agregados = 0;

    while (!h.empty()){
        auto [costo, v] = h.top();
        h.pop();
        if (enX[v]) continue;

        enX[v] = true;
        total += costo;
        agregados++;

        for (auto [w, c] : g[v])
            if (!enX[w]) h.push({c, w});
    }
    return agregados == n ? total : -1;
}

Programación dinámica: método y MWIS

Probabilidad: muy alta

Cuándo: hay decisiones encadenadas, un voraz falla y los subproblemas se repiten. El método de clases tiene tres pasos:

  • Subproblemas: ¿qué tabla guardo? Pocos estados, y que cada uno se calcule rápido.
  • Recurrencia: mirar la última decisión. ¿Qué casos hay y a qué subproblema lleva cada uno?
  • Respuesta: ¿qué celda la tiene? ¿Piden reconstruir la solución?

El costo es (número de estados) × (trabajo por estado) + reconstrucción. Se puede escribir top-down (recursión con memo) o bottom-up (tabla). Bottom-up evita desbordar la pila con n grande.

Para reconstruir: parte en la celda final y pregunta en cada paso qué caso ganó.

MWIS en un camino. A[0] = 0, A[1] = w1 y A[i] = max(A[i−1], A[i−2] + wi): el último vértice no se usa, o se usa y bloquea al anterior.

#include <bits/stdc++.h>
using namespace std;

/*
 * llenar
 * Inputs: w -> pesos de los vertices del camino.
 * Return: arreglo A donde A[i] es el peso maximo usando los primeros i vertices.
 * Que hace: A[i] = max(A[i-1], A[i-2] + w_i): el ultimo vertice se excluye o se
 *           incluye. O(n).
 */
vector<long long> llenar(const vector<long long>& w){
    int n = w.size();
    vector<long long> A(n + 1, 0);

    if (n >= 1) A[1] = w[0];
    for (int i = 2; i <= n; i++)
        A[i] = max(A[i - 1], A[i - 2] + w[i - 1]);
    return A;
}

/*
 * reconstruir
 * Inputs: A -> tabla ya llena; w -> pesos.
 * Return: indices (desde 1, crecientes) de un conjunto independiente optimo.
 * Que hace: recorre desde el final preguntando que caso gano en cada A[i]. O(n).
 */
vector<int> reconstruir(const vector<long long>& A, const vector<long long>& w){
    vector<int> S;
    int i = w.size();

    while (i >= 2){
        if (A[i - 1] >= A[i - 2] + w[i - 1]){
            i--;
        } else {
            S.push_back(i);
            i -= 2;
        }
    }
    if (i == 1) S.push_back(1);

    reverse(S.begin(), S.end());
    return S;
}

Mochila

Probabilidad: alta

Cuándo: elegir un subconjunto con un presupuesto. A[i][c] es el mejor valor con los primeros i objetos y capacidad c: o el objeto i no entra, o entra (si cabe) y queda capacidad c − si.

Costo O(n · C). Es pseudopolinomial: depende del valor de C, no del número de bits para escribirlo.

Variantes

  • Solo el valor: una fila, con capacidad de mayor a menor (O(C) de memoria).
  • Con repetición: la misma fila, pero con capacidad de menor a mayor.
  • Fraccionaria: voraz por valor/peso.
  • C enorme y n chico (n ≤ 30 aprox.): la tabla no cabe, usa backtracking con cota.
  • Valores chicos y pesos enormes: intercambia los papeles: A[v] = menor peso para lograr el valor v.
#include <bits/stdc++.h>
using namespace std;

/*
 * llenar
 * Inputs: v, s -> valor y tamano de cada objeto; C -> capacidad.
 * Return: matriz A donde A[i][c] es el valor maximo con los primeros i objetos y
 *         capacidad c.
 * Que hace: el objeto i no se usa, o se usa si cabe. O(n * C) tiempo y memoria.
 */
vector<vector<long long>> llenar(const vector<long long>& v, const vector<int>& s, int C){
    int n = v.size();
    vector<vector<long long>> A(n + 1, vector<long long>(C + 1, 0));

    for (int i = 1; i <= n; i++){
        for (int c = 0; c <= C; c++){
            A[i][c] = A[i - 1][c];
            if (s[i - 1] <= c)
                A[i][c] = max(A[i][c], A[i - 1][c - s[i - 1]] + v[i - 1]);
        }
    }
    return A;
}

/*
 * reconstruir
 * Inputs: A -> matriz ya llena; v, s -> objetos; C -> capacidad.
 * Return: indices (desde 1, crecientes) de los objetos de una solucion optima.
 * Que hace: desde A[n][C] pregunta si incluir i explica el valor. O(n).
 */
vector<int> reconstruir(const vector<vector<long long>>& A, const vector<long long>& v, const vector<int>& s, int C){
    vector<int> elegidos;
    int c = C;

    for (int i = (int)v.size(); i >= 1; i--){
        if (s[i - 1] <= c && A[i - 1][c - s[i - 1]] + v[i - 1] >= A[i - 1][c]){
            elegidos.push_back(i);
            c -= s[i - 1];
        }
    }
    reverse(elegidos.begin(), elegidos.end());
    return elegidos;
}

/*
 * mochilaUnaFila
 * Inputs: v, s -> objetos; C -> capacidad.
 * Return: valor maximo, usando O(C) memoria.
 * Que hace: la capacidad va de mayor a menor para que cada objeto se use una
 *           sola vez. Si fuera de menor a mayor seria mochila con repeticion.
 */
long long mochilaUnaFila(const vector<long long>& v, const vector<int>& s, int C){
    vector<long long> A(C + 1, 0);

    for (int i = 0; i < (int)v.size(); i++)
        for (int c = C; c >= s[i]; c--)
            A[c] = max(A[c], A[c - s[i]] + v[i]);
    return A[C];
}

Ejemplo de la lámina: C = 6, objetos (valor, tamaño) = (3,4), (2,3), (4,2), (4,3). El óptimo es A[4][6] = 8 con los objetos 3 y 4 (tamaño 5). A[3][5] = 6 significa: con los primeros 3 objetos y capacidad 5 se llega a valor 6.

Alineamiento de secuencias

Probabilidad: alta

Cuándo: dos secuencias que hay que comparar: ignorar, insertar o emparejar elementos, con costos.

Idea. A[i][j] es el costo mínimo de alinear los primeros i de X con los primeros j de Y. La última columna solo puede ser una de tres: (xi, yj), (xi, espacio) o (espacio, yj). Caso base: A[i][0] = i · gap y A[0][j] = j · gap.

Variantes, cambiando solo los costos

  • Distancia de edición (ayudantía del 7 nov): gap = 1 y distintos = 1.
  • LCS (subsecuencia común más larga): gap = 1 y distintos = 2. El largo es (m + n − costo) / 2.
  • Comodín que empareja con cualquiera: cambia la función de costo (C26·D).
  • Maximizar puntaje: cambia min por max y usa puntajes.
#include <bits/stdc++.h>
using namespace std;

/*
 * llenar
 * Inputs: x, y -> cadenas; gap -> costo de un espacio; dif -> costo de enfrentar
 *         simbolos distintos (iguales cuestan 0).
 * Return: matriz A donde A[i][j] es el costo minimo de alinear los primeros i de
 *         x con los primeros j de y.
 * Que hace: la ultima columna es (x_i, y_j), (x_i, gap) o (gap, y_j). O(m * n).
 */
vector<vector<int>> llenar(const string& x, const string& y, int gap, int dif){
    int m = x.size(), n = y.size();
    vector<vector<int>> A(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) A[i][0] = i * gap;
    for (int j = 1; j <= n; j++) A[0][j] = j * gap;

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            A[i][j] = min({A[i - 1][j - 1] + (x[i - 1] == y[j - 1] ? 0 : dif),
                           A[i - 1][j] + gap,
                           A[i][j - 1] + gap});
    return A;
}

/*
 * reconstruir
 * Inputs: A -> matriz ya llena; x, y, gap, dif -> los mismos de llenar.
 * Return: par con las dos filas de una alineacion optima, con '-' como espacio.
 * Que hace: parte en A[m][n] y retrocede por el caso que dio el minimo. Las
 *           columnas salen al reves, por eso se invierten al final. O(m + n).
 */
pair<string, string> reconstruir(const vector<vector<int>>& A, const string& x, const string& y, int gap, int dif){
    string a, b;
    int i = x.size(), j = y.size();

    while (i > 0 || j > 0){
        if (i > 0 && j > 0 && A[i][j] == A[i - 1][j - 1] + (x[i - 1] == y[j - 1] ? 0 : dif)){
            a += x[--i];
            b += y[--j];
        } else if (i > 0 && A[i][j] == A[i - 1][j] + gap){
            a += x[--i];
            b += '-';
        } else {
            a += '-';
            b += y[--j];
        }
    }
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    return {a, b};
}

Pregunta de la clase: X = AGTACG, Y = ACATAG, gap = 1, distintos = 2. El puntaje NW es 4, con A-GTACG sobre ACATA-G. No se puede bajar de 4.

ABB óptimo

Probabilidad: baja

Cuándo: claves en orden con frecuencias, y hay que armar el árbol de búsqueda que minimice el costo promedio. Es la PD por intervalos más típica.

Idea (Roughgarden, cap. 17). Costo = suma de pi · (profundidadi + 1). C[i][j] es el óptimo con las claves i a j. Si la raíz es r, todas las claves del intervalo bajan un nivel, así que:

C[i][j] = (pi + ... + pj) + min sobre r de (C[i][r−1] + C[r+1][j]), con el intervalo vacío en 0.

Se llena por largo creciente del intervalo, y las sumas salen de sumas acumuladas. O(n3).

Ojo: esta clase es del 10 de noviembre y no está en la carpeta. CLRS (sección 15.5) incluye además claves ficticias para las búsquedas fallidas: el intervalo vacío vale qi−1 en vez de 0. Revisa cuál usó la profesora.

#include <bits/stdc++.h>
using namespace std;

/*
 * abbOptimo
 * Inputs: p -> frecuencia de cada clave, en orden creciente de clave.
 * Return: minimo de la suma de p_i * (profundidad_i + 1) sobre todos los ABB.
 * Que hace: PD por intervalos. C[i][j] es el costo optimo con las claves i..j. Si
 *           la raiz es r, toda clave baja un nivel, lo que suma p_i + ... + p_j, y
 *           quedan los subproblemas i..r-1 y r+1..j. El intervalo vacio cuesta 0.
 *           Se llena por largo creciente. O(n^3).
 */
long long abbOptimo(const vector<long long>& p){
    int n = p.size();
    vector<long long> suma(n + 1, 0);
    for (int i = 1; i <= n; i++) suma[i] = suma[i - 1] + p[i - 1];

    vector<vector<long long>> C(n + 2, vector<long long>(n + 2, 0));

    for (int largo = 1; largo <= n; largo++){
        for (int i = 1; i + largo - 1 <= n; i++){
            int j = i + largo - 1;
            long long mejor = LLONG_MAX;
            for (int r = i; r <= j; r++)
                mejor = min(mejor, C[i][r - 1] + C[r + 1][j]);
            C[i][j] = mejor + suma[j] - suma[i - 1];
        }
    }
    return C[1][n];
}

Ejemplo (Roughgarden): frecuencias 0,20; 0,05; 0,17; 0,10; 0,20; 0,03; 0,25. El costo óptimo es 2,23. Con enteros multiplicados por 100 el programa da 223.

Bellman-Ford

Probabilidad: muy alta

Cuándo: camino más corto desde una fuente con pesos negativos, o detectar ciclos negativos. Siempre que n · m quepa.

Idea (clase de Bellman-Ford). Li,v es la longitud mínima hasta v usando a lo más i aristas: o ya se llegaba con i − 1, o se llega por una última arista (w, v):

Li,v = min(Li−1,v, min sobre (w,v) de Li−1,w + ℓwv)

Un camino simple tiene a lo más n − 1 aristas. Si la pasada n todavía mejora algo, hay un ciclo negativo alcanzable. Si una pasada no cambia nada, se puede terminar antes.

Relajar en un solo arreglo (como aquí) converge igual o más rápido que la matriz de la clase, y usa O(n) de memoria.

Variantes

  • Recuperar el ciclo (ayudantía del 14 nov): guarda padre, retrocede n veces para caer dentro del ciclo y dale la vuelta.
  • Cualquier ciclo negativo, aunque no sea alcanzable desde s: inicializa todas las distancias en 0.
  • Maximizar: multiplica los pesos por −1. Un ciclo positivo pasa a ser negativo.
#include <bits/stdc++.h>
using namespace std;

const long long INF = LLONG_MAX / 2;

struct Arista { int u, v; long long w; };

/*
 * bellmanFord
 * Inputs: n -> vertices 1..n; aristas -> lista dirigida; s -> fuente;
 *         dist -> donde se dejan las distancias.
 * Return: los vertices de un ciclo negativo alcanzable desde s, en orden y con
 *         el primero repetido al final; vacio si no existe.
 * Que hace: guarda en padre[v] quien relajo a v por ultima vez. Si la pasada n
 *           relaja a x, x depende de un ciclo negativo. Retroceder n veces por
 *           padre asegura caer dentro del ciclo, y desde ahi se le da la vuelta.
 */
vector<int> bellmanFord(int n, const vector<Arista>& aristas, int s, vector<long long>& dist){
    dist.assign(n + 1, INF);
    vector<int> padre(n + 1, -1);
    dist[s] = 0;

    int x = -1;
    for (int i = 1; i <= n; i++){
        x = -1;
        for (const Arista& e : aristas){
            if (dist[e.u] != INF && dist[e.u] + e.w < dist[e.v]){
                dist[e.v] = dist[e.u] + e.w;
                padre[e.v] = e.u;
                x = e.v;
            }
        }
        if (x == -1) return {};
    }

    for (int i = 0; i < n; i++) x = padre[x];

    vector<int> ciclo = {x};
    for (int v = padre[x]; v != x; v = padre[v]) ciclo.push_back(v);
    ciclo.push_back(x);
    reverse(ciclo.begin(), ciclo.end());
    return ciclo;
}

Floyd-Warshall

Probabilidad: alta

Cuándo: distancias entre todo par con n ≤ 500, o un problema de encadenar transformaciones sobre pocos elementos (T25·I, con 26 letras).

Idea. A[k][i][j] es lo mínimo de i a j usando solo los primeros k vértices como intermedios: o no se usa k, o se pasa por k una vez. En la práctica basta una matriz, con k en el ciclo externo. O(n3).

Hay ciclo negativo si algún d[v][v] < 0. Un par (u, v) es −∞ si existe t con d[t][t] < 0 alcanzable desde u y que alcance a v.

Antes de correr: d[i][i] = 0, cada arista con su mínimo si vienen repetidas, e INF en el resto.

Ojo: la clase es del 17 de noviembre y no está en la carpeta. La idea viene de Roughgarden, cap. 18.

#include <bits/stdc++.h>
using namespace std;

const long long INF = (long long)1e18;

/*
 * floyd
 * Inputs: d -> matriz con d[i][i] = 0 y cada arista directa, INF si no hay;
 *         sig -> sig[i][j] es el primer salto de i hacia j, -1 si no hay camino.
 * Return: nada; deja las distancias minimas en d y los saltos en sig.
 * Que hace: el k del ciclo externo es el vertice que se permite como intermedio.
 *           El max con -INF evita desbordes cuando hay ciclos negativos. O(n^3).
 */
void floyd(vector<vector<long long>>& d, vector<vector<int>>& sig){
    int n = d.size();
    for (int k = 0; k < n; k++){
        for (int i = 0; i < n; i++){
            for (int j = 0; j < n; j++){
                if (d[i][k] == INF || d[k][j] == INF) continue;
                long long via = max(-INF, d[i][k] + d[k][j]);
                if (via < d[i][j]){
                    d[i][j] = via;
                    sig[i][j] = sig[i][k];
                }
            }
        }
    }
}

/*
 * afectado
 * Inputs: d -> matriz ya procesada; u, v -> par consultado.
 * Return: true si entre u y v pasa un ciclo negativo (la distancia es -infinito).
 * Que hace: busca un t con d[t][t] < 0 alcanzable desde u y que alcance a v.
 */
bool afectado(const vector<vector<long long>>& d, int u, int v){
    int n = d.size();
    for (int t = 0; t < n; t++)
        if (d[u][t] != INF && d[t][t] < 0 && d[t][v] != INF) return true;
    return false;
}

/*
 * camino
 * Inputs: sig -> tabla de saltos; u, v -> extremos, con camino y sin ciclo negativo.
 * Return: los vertices del camino minimo de u a v.
 */
vector<int> camino(const vector<vector<int>>& sig, int u, int v){
    vector<int> r = {u};
    while (u != v){
        u = sig[u][v];
        r.push_back(u);
    }
    return r;
}

BFS y Dijkstra

Probabilidad: muy baja

No están en el temario del C2, pero conviene tenerlos a mano si aparece un grafo con n grande. BFS da la mínima cantidad de aristas. Dijkstra da distancias mínimas si todos los pesos son no negativos, en O(m log n): sirve donde Bellman-Ford, O(n · m), no alcanza.

#include <bits/stdc++.h>
using namespace std;

const long long INF = LLONG_MAX / 2;
typedef pair<long long, int> Par;

/*
 * bfs
 * Inputs: g -> lista de adyacencia (0..n-1); s -> fuente.
 * Return: cantidad minima de aristas desde s a cada vertice, -1 si no se llega.
 * Que hace: recorrido por niveles con una cola. O(n + m).
 */
vector<int> bfs(const vector<vector<int>>& g, int s){
    vector<int> d(g.size(), -1);
    queue<int> q;
    d[s] = 0;
    q.push(s);

    while (!q.empty()){
        int v = q.front();
        q.pop();
        for (int w : g[v]){
            if (d[w] == -1){
                d[w] = d[v] + 1;
                q.push(w);
            }
        }
    }
    return d;
}

/*
 * dijkstra
 * Inputs: g -> lista con (vecino, costo >= 0); s -> fuente.
 * Return: distancia minima a cada vertice, INF si no se llega.
 * Que hace: saca siempre el vertice pendiente mas cercano. Solo es correcto sin
 *           aristas negativas; con negativas se usa Bellman-Ford. O(m log n).
 */
vector<long long> dijkstra(const vector<vector<pair<int, long long>>>& g, int s){
    vector<long long> d(g.size(), INF);
    priority_queue<Par, vector<Par>, greater<Par>> h;
    d[s] = 0;
    h.push({0, s});

    while (!h.empty()){
        auto [dv, v] = h.top();
        h.pop();
        if (dv != d[v]) continue;
        for (auto [w, c] : g[v]){
            if (dv + c < d[w]){
                d[w] = dv + c;
                h.push({d[w], w});
            }
        }
    }
    return d;
}

C26·B

La Guardia de la Noche

C2 2026-1 · BmedioS3

Enunciado. M ≤ 25 voluntarios con campus, arma y facción. Sirven solo los de campus oficial (CasaCentral, SanJoaquin, Vitacura, VinaDelMar, Concepcion) con arma Vidriagon o AceroValyrio. Contar los escuadrones de exactamente K útiles sin mezclar Stark con Lannister. Los Neutral van con cualquiera.

Cómo se reconoce. «De cuántas maneras elegir exactamente K» con M ≤ 25, y no importa el orden. C(25,12) es unos 5,2 millones: cabe.

Idea. Primero se filtra. Después son combinaciones con el esquema de clases: elegir un índice desde inicio, verificar y explorar con i + 1. El estado que hay que recordar es mínimo: cuántos faltan y si ya entró un Stark o un Lannister. Como esos dos datos van por valor, no hay nada que deshacer. Se poda si no quedan voluntarios suficientes y si la elección mezcla facciones.

Se puede resolver sin backtracking. Si s, l y e son los útiles Stark, Lannister y Neutral, el total es C(s+e, K) + C(l+e, K) − C(e, K). Se resta porque los escuadrones solo de neutrales se contaron en los dos primeros términos. El resultado coincide con el backtracking en todos los casos de prueba.

Trampas.
  • «Stark» o «Lannister» como campus no son válidos: JonNieve queda fuera aunque su arma sirva.
  • K puede ser mayor que la cantidad de útiles: la respuesta es 0, y la poda lo resuelve sola.

Costo. O(C(M,K)) en el peor caso: 0,09 s con M = 25 y K = 12.

#include <bits/stdc++.h>
using namespace std;

/*
 * generar
 * Inputs: f -> faccion de cada voluntario util (0 neutral, 1 Stark, 2 Lannister).
 *         inicio -> primer indice que todavia se puede elegir.
 *         faltan -> cuantos guerreros faltan para completar K.
 *         stark, lannister -> si el escuadron ya tiene a alguien de esa faccion.
 * Return: cantidad de escuadrones validos que se pueden completar desde aqui.
 * Que hace: backtracking de combinaciones: elige un i >= inicio, verifica que no
 *           junte Stark con Lannister y explora desde i + 1. Se poda si ya no
 *           quedan voluntarios suficientes y si la eleccion mezcla facciones.
 */
long long generar(const vector<int>& f, int inicio, int faltan, bool stark, bool lannister){
    if (faltan == 0) return 1;

    long long total = 0;
    int n = f.size();
    for (int i = inicio; i < n && n - i >= faltan; i++){
        bool s = stark || f[i] == 1;
        bool l = lannister || f[i] == 2;
        if (s && l) continue;
        total += generar(f, i + 1, faltan - 1, s, l);
    }
    return total;
}

/*
 * main
 * Inputs (stdin): M y K, luego M lineas con nombre, campus, arma y faccion.
 * Return: 0
 * Que hace: filtra a los voluntarios que cumplen campus y arma, y cuenta los
 *           escuadrones de exactamente K con generar.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    const set<string> campus = {"CasaCentral", "SanJoaquin", "Vitacura", "VinaDelMar", "Concepcion"};
    const set<string> armas = {"Vidriagon", "AceroValyrio"};

    int m, k;
    cin >> m >> k;

    vector<int> f;
    for (int i = 0; i < m; i++){
        string nombre, c, a, fa;
        cin >> nombre >> c >> a >> fa;
        if (campus.count(c) && armas.count(a))
            f.push_back(fa == "Stark" ? 1 : (fa == "Lannister" ? 2 : 0));
    }

    cout << generar(f, 0, k, false, false) << "\n";
    return 0;
}
T24·D

Anti-Hacking

Torneo 2024-2 · Dmedio

Enunciado. n ≤ 10 letras que pueden repetirse. Contar las contraseñas distintas que usan todas las letras, sin dos letras iguales seguidas y que no empiezan con la letra menor del conjunto.

Cómo se reconoce. n ≤ 10 y el orden importa: permutaciones. «Distintas» con repetidos: ojo con contar dos veces.

Idea. Si se permuta por posiciones del arreglo, b₁ c d b₂ y b₂ c d b₁ son la misma contraseña y se cuentan dos veces. La solución es hacer el backtracking por letra distinta, con un contador por letra: en cada posición se prueba cada letra que aún quede. Se verifica al elegir (distinta de la anterior; en la primera posición, distinta de la menor), así que nunca se desarrolla una rama inválida.

Trampas.
  • «Menor» es la menor del conjunto dado, no la letra a.
  • Las mayúsculas y minúsculas son letras distintas. El map las deja ordenadas por ASCII.

Costo. A lo más n! hojas: unos 3,3 millones con 10 letras distintas, 0,11 s.

#include <bits/stdc++.h>
using namespace std;

/*
 * contar
 * Inputs: cuantas -> cuantas veces queda cada letra distinta, ordenadas de menor
 *         a mayor (la posicion 0 es la letra menor); faltan -> posiciones por
 *         llenar; ultima -> indice de la letra anterior (-1 en la primera).
 * Return: cantidad de contrasenas fuertes distintas que se pueden completar.
 * Que hace: backtracking por letras distintas y no por posiciones del arreglo:
 *           asi dos letras iguales no generan la misma contrasena dos veces.
 */
long long contar(vector<int>& cuantas, int faltan, int ultima){
    if (faltan == 0) return 1;

    long long total = 0;
    for (int c = 0; c < (int)cuantas.size(); c++){
        if (cuantas[c] == 0 || c == ultima) continue;
        if (ultima == -1 && c == 0) continue;

        cuantas[c]--;
        total += contar(cuantas, faltan - 1, c);
        cuantas[c]++;
    }
    return total;
}

/*
 * main
 * Inputs (stdin): n y las n letras.
 * Return: 0
 * Que hace: cuenta cada letra con un map, que ya las deja ordenadas.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    map<char, int> frecuencia;
    for (int i = 0; i < n; i++){
        char c;
        cin >> c;
        frecuencia[c]++;
    }

    vector<int> cuantas;
    for (auto& par : frecuencia) cuantas.push_back(par.second);

    cout << contar(cuantas, n, -1) << "\n";
    return 0;
}

Enunciado. Palabra con a lo más 10 guiones bajos. Contar las formas de reemplazarlos por mayúsculas de modo que no haya 3 vocales seguidas, ni 3 consonantes seguidas, y aparezca al menos una L.

Cómo se reconoce. 26 letras por hueco serían 2610. Pero la regla solo distingue tres clases de letra.

#include <bits/stdc++.h>

const long long FORMAS_OTRA_CONSONANTE = 20;

/*
 * esVocal

 * Return: true si c es A, E, I, O o U.
 */
bool esVocal(char c){
    return VOCALES.find(c) != string::npos;
}

/*
 * rompeRegla
 * Inputs: palabra -> string ya rellenado desde 0 hasta i.
 *         i -> ultima posicion que se relleno.
 * Return: true si las posiciones i - 2, i - 1 e i son las tres vocales o las
 *         tres consonantes.
 * Que hace: como cada letra nueva solo puede formar un trio malo con las dos
 *           anteriores, basta revisar esa ventana para saber si el prefijo
 *           sigue siendo valido.
 */
bool rompeRegla(const string &palabra, int i){
    if (i < 2) return false;
    bool a = esVocal(palabra[i - 2]);
    bool b = esVocal(palabra[i - 1]);
    bool c = esVocal(palabra[i]);
    return a == b && b == c;
}

/*
 * contar
 * Inputs: palabra -> string con letras y '_' (se modifica y se restaura).
 *         i -> posicion que toca decidir.
 *         tieneL -> true si en palabra[0..i-1] ya aparece una 'L'.
 * Return: cantidad de palabras agradables que se forman rellenando los '_'
 *         desde la posicion i en adelante.
 * Que hace: backtracking que en cada '_' no prueba las 26 letras, sino solo
 *           3 representantes, porque la regla solo distingue tres clases.
 */
long long contar(string &palabra, int i, bool tieneL){
    if (i == (int)palabra.size()) return tieneL ? 1 : 0;

    if (palabra[i] != '_'){
        if (rompeRegla(palabra, i)) return 0;
        return contar(palabra, i + 1, tieneL || palabra[i] == 'L');
    }

    const char representante[3] = {'A', 'L', 'B'};
    const long long formas[3] = {FORMAS_VOCAL, FORMAS_L, FORMAS_OTRA_CONSONANTE};

    long long total = 0;
    for (int k = 0; k < 3; k++){
        palabra[i] = representante[k];
        if (!rompeRegla(palabra, i)){
            total += formas[k] * contar(palabra, i + 1, tieneL || representante[k] == 'L');
        }
    }
    palabra[i] = '_';
    return total;
}

Tautology

Listado 3 · Cmedio

Enunciado. Fórmula lógica en notación prefija con variables p, q, r, s, t y operadores K (y), A (o), N (no), C (implica) y E (igual). Decidir si vale 1 para toda asignación.

Cómo se reconoce. 5 variables: solo 25 = 32 filas en la tabla de verdad.

Idea. Cada número de 0 a 31 es una asignación. La evaluación es recursiva: lee un símbolo; si es variable devuelve su bit; si es operador, evalúa sus operandos. pos va por referencia para que cada llamada siga donde terminó la anterior.

Trampas.
  • w y x se calculan en líneas separadas. Con w && x directo, el cortocircuito saltaría la lectura de x y pos quedaría mal.

Costo. 32 × largo.

#include <bits/stdc++.h>
using namespace std;

const string VARIABLES = "pqrst";
const int CANTIDAD_VARIABLES = 5;

/*
 * evaluar
 * Inputs: formula -> WFF en notacion prefija (cada operador va antes de sus operandos).
 *         pos -> indice del simbolo que toca leer. Se pasa por referencia porque
 *                cada llamada avanza sobre los simbolos que consume, y la llamada
 *                que sigue tiene que continuar justo donde termino la anterior.
 *         asignacion -> mascara de 5 bits: el bit i es el valor de VARIABLES[i].
 * Return: valor de verdad de la sub-formula que empieza en pos.
 * Que hace: sigue la misma definicion recursiva de WFF del enunciado.
 */
bool evaluar(const string &formula, int &pos, int asignacion){
    char simbolo = formula[pos++];

    size_t indice = VARIABLES.find(simbolo);
    if (indice != string::npos) return (asignacion >> indice) & 1;

    if (simbolo == 'N') return !evaluar(formula, pos, asignacion);

    bool w = evaluar(formula, pos, asignacion);
    bool x = evaluar(formula, pos, asignacion);
    switch (simbolo){
        case 'K': return w && x;
        case 'A': return w || x;
        case 'C': return !w || x;
        default:  return w == x;
    }
}

/*
 * esTautologia
 * Inputs: formula -> WFF valida de a lo mas 100 simbolos.
 * Return: true si la formula vale 1 para todas las asignaciones posibles.
 * Que hace: fuerza bruta sobre las 2^5 = 32 combinaciones de p, q, r, s, t
 *           (cada numero de 0 a 31 es una fila de la tabla de verdad).
 */
bool esTautologia(const string &formula){
    for (int asignacion = 0; asignacion < (1 << CANTIDAD_VARIABLES); asignacion++){
        int pos = 0;
        if (!evaluar(formula, pos, asignacion)) return false;
    }
    return true;
}

Square Deal

Listado 3 · Emedio

Enunciado. Tres rectángulos que se pueden rotar. ¿Se pueden pegar para formar un cuadrado?

Cómo se reconoce. Pocas piezas: probar todas las configuraciones.

Idea. El lado del cuadrado es el lado más largo de todos. Con 3 piezas siempre hay una franja que cruza el cuadrado entero: se prueba cada pieza, en cada rotación, como esa franja. Si uno de sus lados mide s, deja un hueco de s × (s − otro lado), que las otras dos deben llenar compartiendo un lado completo.

Trampas.
  • Hay que probar las 4 combinaciones de rotación de las dos piezas restantes.

Costo. O(1).

#include <bits/stdc++.h>
using namespace std;

/*
 * llenanHueco
 * Inputs: a, b -> los dos rectangulos restantes, como {lado1, lado2}. Se pueden
 *                 rotar, asi que cualquiera de sus lados puede ir en cualquier eje.
 *         comun -> lado del hueco que los dos deben compartir completo.
 *         largo -> el otro lado del hueco.
 * Return: true si a y b, puestos uno pegado al otro, llenan exacto un hueco
 *         rectangular de comun x largo.
 * Que hace: dos rectangulos solo pueden formar un rectangulo si la linea que
 *           los separa es recta y va de borde a borde.
 */
bool llenanHueco(const int a[2], const int b[2], int comun, int largo){
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            if (a[i] == comun && b[j] == comun && a[1 - i] + b[1 - j] == largo) return true;
    return false;
}

/*
 * formanCuadrado
 * Inputs: r -> los tres rectangulos, r[k] = {alto, ancho}.
 * Return: true si se pueden pegar los tres para formar un cuadrado.
 * Que hace: el lado del cuadrado s tiene que ser el lado mas largo de todos
 *           (ningun rectangulo puede sobresalir, y alguno lo toca de borde a
 *           borde).
 */
bool formanCuadrado(int r[3][2]){
    int s = 0;
    for (int k = 0; k < 3; k++) s = max(s, max(r[k][0], r[k][1]));

    for (int k = 0; k < 3; k++){
        const int *b = r[(k + 1) % 3];
        const int *c = r[(k + 2) % 3];
        for (int i = 0; i < 2; i++){
            if (r[k][i] != s) continue;
            int resto = s - r[k][1 - i];
            if (llenanHueco(b, c, s, resto) || llenanHueco(b, c, resto, s)) return true;
        }
    }
    return false;
}

Veci

Listado 3 · Ddirecto

Enunciado. Dado X, encontrar el menor número mayor que X con los mismos dígitos, o 0 si no existe.

Cómo se reconoce. Es la siguiente permutación, tal cual la clase 15.

Idea. Pivote: el primer x[i] < x[i+1] mirando desde la derecha. Se intercambia con el primero mayor que él desde la derecha y se invierte el sufijo. Con igual cantidad de dígitos, el orden de texto coincide con el numérico.

Trampas.
  • next_permutation hace lo mismo y retorna false si no hay siguiente.

Costo. O(dígitos).

#include <bits/stdc++.h>
using namespace std;

/*
 * siguienteConMismosDigitos
 * Inputs: x -> string con los digitos de X (el primero no es cero).
 * Return: true si existe un numero mayor que X con los mismos digitos, y en
 *         ese caso deja ese numero en x; false si X ya es el mayor posible.
 * Que hace: calcula la siguiente permutacion en orden lexicografico, que para
 *           numeros con la misma cantidad de digitos coincide con el orden
 *           numerico.
 */
bool siguienteConMismosDigitos(string &x){
    int n = x.size();

    int i = n - 2;
    while (i >= 0 && x[i] >= x[i + 1]) i--;
    if (i < 0) return false;

    int j = n - 1;
    while (x[j] <= x[i]) j--;

    swap(x[i], x[j]);
    reverse(x.begin() + i + 1, x.end());
    return true;
}

Championship

Torneo 2025-2 · EdifícilS2

Enunciado. N ≤ 15 problemas con dificultad y categoría (A, B, C, D). Contar las secuencias de exactamente K problemas distintos que cumplan: categorías consecutivas distintas, fatiga total (suma de dificultad × posición) divisible por M, y si parte con A no puede terminar en D.

Cómo se reconoce. Importa el orden y N = 15: 15! es demasiado. Pero el futuro no depende del orden pasado, solo de qué se usó: PD con máscara.

Idea. Para seguir solo importa: qué problemas ya se usaron (máscara), la categoría del último y el resto de la fatiga módulo M. La posición del siguiente es popcount(mascara) + 1, así que no se guarda. Para la regla 4 falta saber si la secuencia partió con A. En vez de agregar otra dimensión, se corre la PD dos veces: una partiendo solo con problemas A (con prohibido terminar en D) y otra con los demás.

Trampas.
  • Memoria: 215 × 4 × 100 valores long long son 105 MB. Un solo arreglo plano, reutilizado.
  • Hay hasta 15! ≈ 1,3 × 1012 secuencias: long long.
Errata: el PDF dice 8 y 10, pero la lectura literal da 4 y 11. Las 4 del primer ejemplo se pueden comprobar a mano: 6B 3C 4A (fatiga 24), 6B 3C 8A (36), 8A 2D 4A (24), 2D 8A 6B (36). Probé posiciones desde 0, 1 y 2, con y sin la regla de categorías, y variantes de la regla 4, y ninguna lectura natural da 8 y 10. El código sigue el enunciado.

Costo. O(2N · 4 · M · N) en el peor caso: 0,38 s con N = K = 15 y M = 100.

#include <bits/stdc++.h>
using namespace std;

/*
 * contar
 * Inputs: d, cat -> dificultad y categoria (0..3) de cada problema;
 *         k, m -> problemas a resolver y modulo; empiezaConA -> que caso contar;
 *         dp -> arreglo de trabajo de tamano 2^n * 4 * m.
 * Return: secuencias validas cuyo primer problema es o no es de categoria A.
 * Que hace: PD sobre subconjuntos. dp[mascara][c][r] cuenta las secuencias que
 *           usan exactamente mascara, terminan en categoria c y tienen fatiga
 *           % m == r. La posicion del siguiente es popcount(mascara) + 1, por
 *           eso no hace falta guardarla. O(2^n * 4 * m * n) en el peor caso.
 */
long long contar(const vector<int>& d, const vector<int>& cat, int k, int m, bool empiezaConA, vector<long long>& dp){
    int n = d.size();
    int total = 1 << n;
    fill(dp.begin(), dp.end(), 0);

    auto id = [&](int mascara, int c, int r){ return (mascara * 4 + c) * m + r; };

    for (int i = 0; i < n; i++)
        if ((cat[i] == 0) == empiezaConA)
            dp[id(1 << i, cat[i], d[i] % m)] = 1;

    long long respuesta = 0;
    for (int mascara = 1; mascara < total; mascara++){
        int usados = __builtin_popcount(mascara);
        if (usados > k) continue;

        for (int c = 0; c < 4; c++){
            for (int r = 0; r < m; r++){
                long long formas = dp[id(mascara, c, r)];
                if (formas == 0) continue;

                if (usados == k){
                    if (r == 0 && !(empiezaConA && c == 3)) respuesta += formas;
                    continue;
                }

                for (int j = 0; j < n; j++){
                    if ((mascara >> j & 1) || cat[j] == c) continue;
                    int nr = (r + d[j] * (usados + 1)) % m;
                    dp[id(mascara | (1 << j), cat[j], nr)] += formas;
                }
            }
        }
    }
    return respuesta;
}

/*
 * main
 * Inputs (stdin): N, K, M y luego N lineas "d c".
 * Return: 0
 * Que hace: separa las secuencias segun si parten con A, porque solo esas tienen
 *           prohibido terminar en D, y suma ambos casos.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k, m;
    cin >> n >> k >> m;

    vector<int> d(n), cat(n);
    for (int i = 0; i < n; i++){
        char c;
        cin >> d[i] >> c;
        cat[i] = c - 'A';
    }

    vector<long long> dp((size_t)(1 << n) * 4 * m);
    cout << contar(d, cat, k, m, true, dp) + contar(d, cat, k, m, false, dp) << "\n";
    return 0;
}

Paintings

Listado 3 · Gdifícil

Enunciado. N ≤ 12 colores en orden de preferencia y pares que no pueden quedar juntos. Contar las pinturas válidas y entregar la favorita: en cada franja, el color más preferido que permita terminar.

Cómo se reconoce. Importa el orden, N = 12, y solo importa qué colores quedan y cuál fue el último.

Idea. formas[mascara][ultimo] cuenta las maneras de terminar desde ese estado, llenando de la máscara completa hacia atrás. Después la favorita se arma con un voraz: en cada franja, el primer color libre que no choca con el anterior y con formas > 0. La PD garantiza que el voraz nunca se queda sin salida.

Trampas.
  • La primera franja no tiene anterior: ultimo = -1.

Costo. O(2N · N2).

#include <bits/stdc++.h>
using namespace std;

const int MAX_COLORES = 12;

/*
 * contarFormas
 * Inputs: n -> cantidad de colores (el indice 0 es el mas preferido).
 *         choca -> choca[a][b] es true si los colores a y b no pueden quedar juntos.
 *         formas -> tabla de 2^n x n que se llena aqui.
 * Return: nada; deja en formas[mascara][ultimo] la cantidad de maneras de
 *         terminar la pintura sin que quede fea, si ya se usaron los colores
 *         de "mascara" y la ultima franja pintada es "ultimo".
 * Que hace: DP sobre subconjuntos (bitmask).
 */
void contarFormas(int n, bool choca[MAX_COLORES][MAX_COLORES], vector<vector<long long>> &formas){
    int completa = (1 << n) - 1;
    formas.assign(1 << n, vector<long long>(n, 0));

    for (int mascara = completa; mascara > 0; mascara--){
        for (int ultimo = 0; ultimo < n; ultimo++){
            if (!(mascara & (1 << ultimo))) continue;
            if (mascara == completa){
                formas[mascara][ultimo] = 1;
                continue;
            }
            long long total = 0;
            for (int c = 0; c < n; c++)
                if (!(mascara & (1 << c)) && !choca[ultimo][c])
                    total += formas[mascara | (1 << c)][c];
            formas[mascara][ultimo] = total;
        }
    }
}

/*
 * pinturaFavorita
 * Inputs: n, choca -> igual que en contarFormas.
 *         formas -> la tabla que dejo contarFormas.
 * Return: los indices de los colores de la pintura favorita, de izquierda a derecha.
 * Que hace: simula a Catherine.
 */
vector<int> pinturaFavorita(int n, bool choca[MAX_COLORES][MAX_COLORES], const vector<vector<long long>> &formas){
    vector<int> pintura;
    int mascara = 0, ultimo = -1;

    for (int franja = 0; franja < n; franja++){
        for (int c = 0; c < n; c++){
            if (mascara & (1 << c)) continue;
            if (ultimo != -1 && choca[ultimo][c]) continue;
            if (formas[mascara | (1 << c)][c] == 0) continue;
            pintura.push_back(c);
            mascara |= 1 << c;
            ultimo = c;
            break;
        }
    }
    return pintura;
}

#include <bits/stdc++.h>

/*
 * minimoGrupos
 * Inputs: a -> habilidades (se ordenan aqui); d -> diferencia maxima permitida.
 * Return: la menor cantidad de grupos.
 * Que hace: voraz sobre el arreglo ordenado: el jugador mas debil sin grupo abre
 *           uno, y entran todos los que esten a distancia <= d de el. Meter a
 *           todos los posibles nunca perjudica a los que siguen. O(n log n).

int minimoGrupos(vector<long long>& a, long long d){

        long long inicio = a[i];
        grupos++;
        while (i < (int)a.size() && a[i] - inicio <= d) i++;
    }
    return grupos;
}

Listado 4 · Cmedio

Enunciado. Cable de largo l. Los pájaros van a distancia ≥ d entre sí y ≥ 6 de los postes. Ya hay n posados. ¿Cuántos más caben?

Cómo se reconoce. Los ya posados parten el cable en huecos independientes.

Idea. En cada hueco conviene ponerlos pegados, a exactamente d. Con división entera: entre vecinos p y q caben (q − p) / d − 1; del poste izquierdo al primero (p − 6) / d; del último al poste derecho (l − 6 − p) / d.

/*
 * pajarosExtra
 * Inputs: l -> largo del cable en cm.
 *         d -> distancia minima entre dos pajaros en cm.
 *         posiciones -> donde estan los pajaros que ya llegaron, en cualquier
 *                       orden (se ordenan aqui).

 * Que hace: los pajaros solo pueden estar en [6, l - 6], y los que ya estan
 *           parten ese tramo en huecos independientes (dos pajaros nuevos en
 *           huecos distintos quedan separados por uno viejo, a 2d o mas), asi
 *           que cada hueco se cuenta por separado.
 */
long long pajarosExtra(long long l, long long d, vector<long long> &posiciones){
    long long inicio = DISTANCIA_POSTE;
    long long fin = l - DISTANCIA_POSTE;

    if (posiciones.empty()){
        if (fin < inicio) return 0;
        return (fin - inicio) / d + 1;
    }

    sort(posiciones.begin(), posiciones.end());

    long long total = (posiciones[0] - inicio) / d;
    for (int i = 0; i + 1 < (int)posiciones.size(); i++)
        total += (posiciones[i + 1] - posiciones[i]) / d - 1;
    total += (fin - posiciones.back()) / d;

    return total;
}

Assigning Workstations

Listado 4 · Bmedio

Enunciado. n investigadores con llegada a y estadía s. Una estación libre se bloquea tras m minutos. Maximizar los desbloqueos ahorrados al reutilizar estaciones.

Cómo se reconoce. Elegir entre recursos que van venciendo: heap.

Idea. Por orden de llegada, con un min-heap del momento en que se desocupa cada estación. Se botan las vencidas (f + m < a). Si el tope ya está libre (f ≤ a) se reutiliza y se ahorra uno. La de f más chico es la primera que vence, y usarla nunca le quita opciones a los que vienen.

Trampas.
  • Primero se botan las vencidas y después se revisa el tope.

#include <bits/stdc++.h>
using namespace std;

/*
 * desbloqueosAhorrados
 * Inputs: investigadores -> pares (a, s): el investigador llega en el minuto a
 *                           y se queda s minutos. Se ordenan aqui por llegada.
 *         m -> minutos sin uso tras los cuales una estacion se bloquea sola.
 * Return: la mayor cantidad de desbloqueos que Penelope se puede ahorrar.
 * Que hace: una estacion que se desocupa en el minuto f le sirve, sin
 *           desbloquearla, a quien llegue en un minuto a con f <= a <= f + m.
 */
int desbloqueosAhorrados(vector<pair<int, int>> &investigadores, int m){
    sort(investigadores.begin(), investigadores.end());

    priority_queue<int, vector<int>, greater<int>> seDesocupa;
    int ahorrados = 0;

    for (int i = 0; i < (int)investigadores.size(); i++){
        int a = investigadores[i].first;
        int s = investigadores[i].second;

        while (!seDesocupa.empty() && seDesocupa.top() + m < a) seDesocupa.pop();

        if (!seDesocupa.empty() && seDesocupa.top() <= a){
            seDesocupa.pop();
            ahorrados++;
        }

        seDesocupa.push(a + s);
    }

    return ahorrados;
}

Boiling Vegetables

Listado 4 · Emedio

Enunciado. N ≤ 1000 trozos. Cada corte divide un trozo. Hallar la mínima cantidad de cortes para que la pieza más chica dividida por la más grande supere T.

Cómo se reconoce. Reducir el máximo poco a poco: voraz sobre el trozo de piezas más grandes.

Idea. Si un trozo queda en k partes, lo mejor es que sean iguales. Mientras no se cumpla la razón, se le da un corte más al trozo con las piezas más grandes. Las fracciones se comparan multiplicando cruzado.

Trampas.
  • T × 100 se redondea con llround.
  • No comparar con double.

Costo. O(cortes · N), con menos de 500 cortes.

#include <bits/stdc++.h>
using namespace std;

/*
 * esMasGrande
 * Inputs: pesoA, partesA -> un trozo de peso pesoA cortado en partesA partes iguales.
 *         pesoB, partesB -> lo mismo para otro trozo.
 * Return: true si pesoA / partesA > pesoB / partesB.
 * Que hace: compara las dos fracciones multiplicando cruzado, para trabajar
 *           solo con enteros y no tener errores de redondeo.
 */
bool esMasGrande(long long pesoA, long long partesA, long long pesoB, long long partesB){
    return pesoA * partesB > pesoB * partesA;
}

/*
 * minimoDeCortes
 * Inputs: t -> el umbral T multiplicado por 100. T trae 2 decimales, asi que
 *              t es entero (0.99 -> 99).
 *         pesos -> peso de cada trozo inicial.
 * Return: la menor cantidad de cortes para que
 *         (pieza mas chica) / (pieza mas grande) > T.
 * Que hace: si un trozo va a quedar en k partes, lo mejor es que sean iguales
 *           (peso / k cada una), con k - 1 cortes.
 */
int minimoDeCortes(int t, const vector<long long> &pesos){
    int n = pesos.size();
    vector<long long> partes(n, 1);

    int menor = 0;
    for (int i = 1; i < n; i++)
        if (esMasGrande(pesos[menor], 1, pesos[i], 1)) menor = i;

    int cortes = 0;
    while (true){
        int mayor = 0;
        for (int i = 1; i < n; i++)
            if (esMasGrande(pesos[i], partes[i], pesos[mayor], partes[mayor])) mayor = i;

        if (esMasGrande(100 * pesos[menor], partes[menor], t * pesos[mayor], partes[mayor])) return cortes;

        partes[mayor]++;
        cortes++;
        if (esMasGrande(pesos[menor], partes[menor], pesos[mayor], partes[mayor])) menor = mayor;
    }
}

Mali

Listado 2 · Emedio

Enunciado. N ≤ 105 rondas. Cada una agrega un A y un B. Emparejar todos los A con todos los B minimizando la mayor suma, e imprimir ese mínimo tras cada ronda.

Cómo se reconoce. Minimizar el máximo de parejas: el menor con el mayor. Valores ≤ 100: histograma.

Idea. Ordenar en cada ronda sería demasiado. Con dos histogramas de 100 casillas, un puntero sube por A y otro baja por B, y en cada paso se emparejan de una vez todas las copias posibles.

Trampas.
  • Las rondas acumulan: no es solo el par nuevo.

Costo. O(100 · N).

#include <bits/stdc++.h>
using namespace std;

const int MAX_VALOR = 100;

int cantidadA[MAX_VALOR + 1];
int cantidadB[MAX_VALOR + 1];
int quedanA[MAX_VALOR + 1];
int quedanB[MAX_VALOR + 1];

/*
 * menorMaximoDeParejas
 * Inputs: usa los arreglos globales cantidadA y cantidadB, que guardan cuantas
 *         veces aparece cada valor entre 1 y 100 en las secuencias A y B
 *         acumuladas hasta la ronda actual.
 * Return: el menor valor posible del maximo a_i + b_j, considerando todas las
 *         formas de emparejar cada numero de A con uno de B.
 * Que hace: aplica la estrategia golosa de emparejar el A mas chico con el B
 *           mas grande, el segundo mas chico con el segundo mas grande, y asi.
 */
int menorMaximoDeParejas(){
    for (int v = 1; v <= MAX_VALOR; v++){
        quedanA[v] = cantidadA[v];
        quedanB[v] = cantidadB[v];
    }

    int i = 1;
    int j = MAX_VALOR;
    int maximo = 0;

    while (i <= MAX_VALOR && j >= 1){
        if (quedanA[i] == 0){
            i++;
            continue;
        }
        if (quedanB[j] == 0){
            j--;
            continue;
        }

        int emparejados = min(quedanA[i], quedanB[j]);
        quedanA[i] -= emparejados;
        quedanB[j] -= emparejados;
        maximo = max(maximo, i + j);
    }

    return maximo;
}
T24·F

Viaje Intergaláctico

Torneo 2024-2 · F, no marcado como válidodifícil

Enunciado. n estaciones en línea, a distancia 1. Una nave con tanque k que parte lleno. Se viaja ida y vuelta. Cada estación tiene un precio por unidad; el primer precio es el que cobra la arrendadora por cada unidad faltante al devolver la nave. Minimizar el costo total.

Cómo se reconoce. Ruta en línea, capacidad y compras por parada: cada unidad que se gasta se pudo comprar solo en una ventana de paradas.

Idea. Sea D = 2(n − 1) la cantidad de tramos y r[0..D] las paradas de ida y vuelta. Se parte con k y se termina con k (lo que falte al volver se paga al precio de r[D] = p1, igual que comprarlo en esa parada), así que se compran exactamente D unidades.

Con consumo en orden de llegada, las primeras k unidades del tanque son las iniciales, y la unidad comprada número e se gasta en el tramo k + e. Esa unidad solo pudo comprarse en una de las k paradas anteriores a ese tramo, sin pasarse de D. Cada unidad toma el mínimo de su ventana y eso siempre es factible: nunca hay más de k unidades esperando. Es una ventana deslizante con deque.

Ejemplo 1 (precios 10, 2, 4 y k = 1): paradas 10, 2, 4, 2, 10. Cada tramo solo puede comprar en la parada justo anterior: 2 + 4 + 2 + 10 = 18.

Trampas.
  • La parada 0 nunca compra (el tanque parte lleno): la ventana arranca en 1.
  • El enunciado no da cotas: long long y O(n).

Costo. O(n).

#include <bits/stdc++.h>
using namespace std;

/*
 * costoOptimo
 * Inputs: p -> precio en cada estacion a lo largo de la ida; k -> capacidad.
 * Return: costo minimo del viaje de ida y vuelta.
 * Que hace: la ruta completa tiene D = 2(n-1) tramos y paradas r[0..D]. Se parte
 *           con k unidades y se termina con k unidades (lo que falta al final se
 *           paga a p[0], que es lo mismo que comprarlo en la parada D), asi que
 *           se compran exactamente D unidades. La unidad e-esima que entra al
 *           tanque se gasta en el tramo k + e, y solo pudo comprarse en una
 *           parada de las ultimas k antes de ese tramo. Cada unidad toma el
 *           minimo de su ventana; ventana deslizante con deque. O(n).
 */
long long costoOptimo(const vector<long long>& p, int k){
    int n = p.size();
    vector<long long> r(p);
    for (int i = n - 2; i >= 0; i--) r.push_back(p[i]);
    int D = 2 * (n - 1);

    deque<int> dq;
    long long total = 0;
    int siguiente = 0;

    for (int tramo = k + 1; tramo <= D + k; tramo++){
        int ini = tramo - k, fin = min(tramo - 1, D);

        while (siguiente <= fin){
            while (!dq.empty() && r[dq.back()] >= r[siguiente]) dq.pop_back();
            dq.push_back(siguiente++);
        }
        while (dq.front() < ini) dq.pop_front();

        total += r[dq.front()];
    }
    return total;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    cin >> n >> k;

    vector<long long> p(n);
    for (int i = 0; i < n; i++) cin >> p[i];

    cout << costoOptimo(p, k) << "\n";
    return 0;
}

Enunciado. n ≤ 105 misiones con duración d, importancia w y líder asignado (Mandaloriano o Bo-Katan). Cada líder hace una misión a la vez. Minimizar la suma de wi · Fi, donde Fi es el día en que termina la misión.

Cómo se reconoce. Tareas con duración y peso, y suma ponderada de tiempos de término: es GreedyRatio tal cual, el de las clases 16 y 17.

Idea. Los dos líderes son independientes: lo que hace uno no afecta al otro. Se separan, en cada uno se ordena por w/d de mayor a menor (comparando cruzado, sin decimales) y se acumula el tiempo.

  • La suma llega a unos 5 × 1017: long long.
  • El enunciado dice letras D y B, y los ejemplos usan M y B. El código revisa solo B.

#include <bits/stdc++.h>

struct Mision { long long d, w; };

/*
 * antes
 * Inputs: a, b -> dos misiones.
 * Return: true si a debe ir antes que b, o sea si w_a / d_a > w_b / d_b.
 * Que hace: compara las razones multiplicando cruzado, sin decimales.

bool antes(const Mision& a, const Mision& b){

 * costoLider

        tiempo += x.d;
        costo += x.w * tiempo;

    return costo;
}

Programación de Hechizos

Torneo 2025-2 · BmedioS2

Enunciado. n ≤ 105 hechizos con tiempo p, peso w y tipo C o D. Cambiar de tipo cuesta S segundos y, una vez cambiado, hay que seguir en el nuevo hasta el final. Minimizar la suma de wi · Ti.

Cómo se reconoce. GreedyRatio con un giro: solo se puede cambiar de tipo una vez.

Idea. Como solo hay un cambio, el orden es un bloque completo de un tipo y después el del otro. Hay solo dos órdenes de bloques: se calculan ambos y se toma el menor. Trampas.

  • El tiempo inicial del segundo bloque es el final del primero más S.

#include <bits/stdc++.h>
using namespace std;

struct Hechizo { long long p, w; };

/*
 * antes
 * Inputs: a, b -> dos hechizos.
 * Return: true si a va antes que b (mayor w/p primero, sin decimales).

bool antes(const Hechizo& a, const Hechizo& b){

/*
 * costoBloque
 * Inputs: v -> hechizos de un tipo, ya ordenados; t -> tiempo al empezar el bloque
 *         (por referencia, termina con el tiempo final del bloque).
 * Return: suma de w * T de los hechizos del bloque.
 */
long long costoBloque(const vector<Hechizo>& v, long long& t){
    long long costo = 0;
    for (const Hechizo& h : v){
        t += h.p;
        costo += h.w * t;
    }
    return costo;
}

 * costoOrden
 * Inputs: primero, segundo -> los dos bloques en ese orden; s -> recalibracion.
 * Return: costo total de ejecutar primero y despues segundo.

    long long costo = costoBloque(primero, t);

}

C25·B

Red de la Resistencia

C2 2025-1 · BdirectoS1

Enunciado. N ≤ 105 zonas y M ≤ 2 × 105 rutas con costo. Restaurar rutas para que todas las zonas queden conectadas, sin ciclos y con la menor cantidad total de baterías.

Cómo se reconoce. «Todas comunicadas», «sin ciclos», costo mínimo: árbol de expansión mínima.

Idea. Kruskal: se ordenan las rutas por costo y se aceptan las que unen dos componentes distintas, consultando con Union-Find. El mismo problema se resuelve con Prim.

Trampas.
  • El enunciado no dice qué hacer si el grafo no es conexo (M puede ser 0): el código imprime el costo del bosque.
  • Hay lazos y aristas repetidas: Union-Find los descarta solo.

Costo. O(M log M).

#include <bits/stdc++.h>
using namespace std;

struct Arista { int u, v; long long c; };

/*
 * buscar
 * Inputs: p -> arreglo de padres; x -> vertice.
 * Return: representante del conjunto de x (comprime el camino).
 */
int buscar(vector<int>& p, int x){
    if (p[x] != x) p[x] = buscar(p, p[x]);
    return p[x];
}

/*
 * unir
 * Inputs: p, tam -> Union-Find; a, b -> vertices.
 * Return: true si estaban en conjuntos distintos y se unieron.
 * Que hace: union por tamano: el arbol chico queda colgando del grande.
 */
bool unir(vector<int>& p, vector<int>& tam, int a, int b){
    a = buscar(p, a);
    b = buscar(p, b);
    if (a == b) return false;
    if (tam[a] < tam[b]) swap(a, b);
    p[b] = a;
    tam[a] += tam[b];
    return true;
}

/*
 * kruskal
 * Inputs: n -> vertices 1..n; aristas -> se ordenan aqui por costo.
 * Return: costo total del bosque de expansion minimo.
 * Que hace: recorre las aristas de menor a mayor y acepta las que no cierran
 *           ciclo. O(m log m).
 */
long long kruskal(int n, vector<Arista>& aristas){
    sort(aristas.begin(), aristas.end(), [](const Arista& a, const Arista& b){ return a.c < b.c; });

    vector<int> p(n + 1), tam(n + 1, 1);
    iota(p.begin(), p.end(), 0);

    long long total = 0;
    for (const Arista& e : aristas)
        if (unir(p, tam, e.u, e.v)) total += e.c;
    return total;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<Arista> aristas(m);
    for (int i = 0; i < m; i++) cin >> aristas[i].u >> aristas[i].v >> aristas[i].c;

    cout << kruskal(n, aristas) << "\n";
    return 0;
}

Juego del Destino

Torneo 2024-2 · Edirecto

Enunciado. Grafo conexo con fichas en cada calle (n ≤ 105, m ≤ 2 × 105). Robert y Rachele recorren todos los puntos usando solo calles que llevan a un punto no visitado. Maximizar la diferencia entre las fichas de uno y otro.

#include <bits/stdc++.h>
using namespace std;

struct Arista { int u, v; long long f; };

/*
 * buscar
 * Inputs: p -> arreglo de padres; x -> vertice.
 * Return: representante del conjunto de x (comprime el camino).
 */
int buscar(vector<int>& p, int x){
    if (p[x] != x) p[x] = buscar(p, p[x]);
    return p[x];
}

/*
 * pesoArbol
 * Inputs: n -> vertices 1..n; aristas -> en el orden en que se quieren evaluar.
 * Return: suma de las aristas que Kruskal acepta en ese orden.
 * Que hace: ordenadas de menor a mayor da el arbol minimo; de mayor a menor, el
 *           arbol maximo. Une por tamano para que buscar no degenere.
 */
long long pesoArbol(int n, const vector<Arista>& aristas){
    vector<int> p(n + 1), tam(n + 1, 1);
    iota(p.begin(), p.end(), 0);

    long long total = 0;
    for (const Arista& e : aristas){
        int a = buscar(p, e.u), b = buscar(p, e.v);
        if (a == b) continue;
        if (tam[a] < tam[b]) swap(a, b);
        p[b] = a;
        tam[a] += tam[b];
        total += e.f;
    }
    return total;
}

/*
 * main
 * Inputs (stdin): n y m, luego m lineas "a b f".
 * Return: 0
 * Que hace: uno recorre el arbol de expansion maximo y el otro el minimo; la
 *           mayor diferencia posible es la resta de ambos.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<Arista> aristas(m);
    for (int i = 0; i < m; i++) cin >> aristas[i].u >> aristas[i].v >> aristas[i].f;

    sort(aristas.begin(), aristas.end(), [](const Arista& a, const Arista& b){ return a.f < b.f; });
    long long minimo = pesoArbol(n, aristas);

    reverse(aristas.begin(), aristas.end());
    long long maximo = pesoArbol(n, aristas);

    cout << maximo - minimo << "\n";
    return 0;
}

/*
 * segunEjemplos
 * Inputs: p -> poderes de los slimes, p[0] es Kirby.
 * Return: maximo poder final segun lo que muestran los ejemplos del PDF.
 * Que hace: MWIS con el slime 1 obligatorio: Kirby cuenta como recien absorbido,
 *           asi que no puede tomar el slime 2, y no se revisa P >= p_i. O(n).
 */
long long segunEjemplos(const vector<long long>& p){
    int n = p.size();
    vector<long long> A(n + 1, 0);

    A[1] = p[0];
    A[2] = p[0];
    for (int i = 3; i <= n; i++)

 * segunEnunciado
 * Inputs: p -> poderes de los slimes, p[0] es Kirby.
 * Return: maximo poder final respetando P >= p_i tal como esta escrito.
 * Que hace: PD con dos estados por slime: libre (el anterior no se absorbio) y
 *           recien (el anterior si). Con el mismo estado, mas poder nunca es
 *           peor, por eso basta guardar el maximo de cada uno. O(n).
 */
long long segunEnunciado(const vector<long long>& p){
    const long long IMPOSIBLE = -1;
    long long libre = p[0], recien = IMPOSIBLE;

    for (int i = 1; i < (int)p.size(); i++){
        long long nuevoLibre = max(libre, recien);
        long long nuevoRecien = (libre >= p[i]) ? libre + p[i] : IMPOSIBLE;
        libre = nuevoLibre;
        recien = nuevoRecien;
    }
    return max(libre, recien);
}

C2 2025-1 · EmedioS1

Enunciado. Cadena de n ≤ 105 paréntesis. Largo de la subcadena contigua balanceada más larga.

Cómo se reconoce. Paréntesis: pila. También sale con PD: D[i] = largo del tramo válido que termina en i.

#include <bits/stdc++.h>
using namespace std;

/*
 * masLarga
 * Inputs: s -> cadena de parentesis.
 * Return: largo de la subcadena contigua balanceada mas larga.
 * Que hace: la pila guarda indices. En el fondo siempre queda el indice justo
 *           antes del tramo valido actual (parte en -1). Cada '(' se apila; cada
 *           ')' desapila, y si la pila queda vacia ese ')' es el nuevo tope del
 *           fondo; si no, el tramo valido mide i - pila.back(). O(n).
 */
int masLarga(const string& s){
    vector<int> pila = {-1};
    int mejor = 0;

    for (int i = 0; i < (int)s.size(); i++){
        if (s[i] == '('){
            pila.push_back(i);
        } else {
            pila.pop_back();
            if (pila.empty()) pila.push_back(i);
            else mejor = max(mejor, i - pila.back());
        }
    }
    return mejor;
}

  • (n + 1) × (m + 1) enteros son 4 MB: sin problema.

Costo. O(n · m).

#include <bits/stdc++.h>
using namespace std;

const int GAP = 2;

/*
 * costoPareja
 * Inputs: a, b -> dos codigos de evento.
 * Return: 0 si son iguales, 1 si alguno es UNK, 5 si son distintos.
 */
int costoPareja(const string& a, const string& b){
    if (a == b) return 0;
    if (a == "UNK" || b == "UNK") return 1;
    return 5;
}

/*
 * costoMinimo
 * Inputs: x, y -> los dos registros.
 * Return: costo minimo de alinearlos (Needleman-Wunsch).
 * Que hace: A[i][j] es el costo de alinear los primeros i de x con los primeros
 *           j de y. La ultima columna es pareja (x[i], y[j]), o x[i] ignorado,
 *           o y[j] ignorado. O(n * m) tiempo y memoria.
 */
int costoMinimo(const vector<string>& x, const vector<string>& y){
    int n = x.size(), m = y.size();
    vector<vector<int>> A(n + 1, vector<int>(m + 1, 0));

    for (int i = 1; i <= n; i++) A[i][0] = i * GAP;
    for (int j = 1; j <= m; j++) A[0][j] = j * GAP;

    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            A[i][j] = min({A[i - 1][j - 1] + costoPareja(x[i - 1], y[j - 1]),
                           A[i - 1][j] + GAP,
                           A[i][j - 1] + GAP});
    return A[n][m];
}

Torneo 2025-2 · FmedioS2

Enunciado. Grilla n × m (hasta 1000) con huevos. Partir en (1,1), moverse solo abajo o a la derecha, y pasar obligatoriamente por la casilla (x, y). Maximizar los huevos recogidos.

#include <bits/stdc++.h>
using namespace std;

/*
 * mejorCamino
 * Inputs: g -> grilla; (f0, c0) -> casilla de partida; (f1, c1) -> casilla de
 *         llegada, abajo y a la derecha de la de partida.
 * Return: maxima cantidad de huevos en un camino entre ambas, moviendo solo
 *         abajo o a la derecha, contando las dos casillas de los extremos.
 * Que hace: PD en grilla: A[i][j] = huevo(i, j) + max(A[i-1][j], A[i][j-1]),
 *           dentro del rectangulo entre los dos extremos. O(filas * columnas).
 */
int mejorCamino(const vector<string>& g, int f0, int c0, int f1, int c1){
    int filas = f1 - f0 + 1, cols = c1 - c0 + 1;
    vector<vector<int>> A(filas, vector<int>(cols, 0));

    for (int i = 0; i < filas; i++){
        for (int j = 0; j < cols; j++){
            int previo = 0;
            if (i > 0) previo = max(previo, A[i - 1][j]);
            if (j > 0) previo = max(previo, A[i][j - 1]);
            A[i][j] = previo + (g[f0 + i][c0 + j] == '0' ? 1 : 0);
        }
    }
    return A[filas - 1][cols - 1];
}

/*
 * main
 * Inputs (stdin): n y m, luego x e y (x es columna, y es fila), luego la grilla.
 * Return: 0
 * Que hace: un camino que pasa por (fila y, columna x) es un tramo hasta ella y
 *           otro desde ella; se maximizan por separado y se resta la casilla
 *           obligatoria, que quedo contada dos veces. Si los indices no caben,
 *           los intercambia (el enunciado se contradice en sus cotas).
 */
int main(){
    ios::sync_with_stdio(false);

    int n, m, x, y;

    for (int i = 0; i < n; i++) cin >> g[i];

    int f = y - 1, c = x - 1;
    int total = mejorCamino(g, 0, 0, f, c) + mejorCamino(g, f, c, n - 1, m - 1);
    if (g[f][c] == '0') total--;

    cout << total << "\n";
    return 0;
}

Enunciado. Grafo dirigido con n, m ≤ 103 y pesos entre −103 y 103. Desde el usuario 1, todos alcanzables. Imprimir la distancia mínima a 2..n, o Negative feedback si hay un ciclo negativo alcanzable.

Cómo se reconoce. Pesos negativos, «ciclo negativo», una fuente: Bellman-Ford tal cual.

Idea. La plantilla sin cambios: hasta n pasadas relajando todas las aristas. Si la pasada n todavía cambia algo, hay ciclo. Hay que imprimir de 2 a n, sin el usuario 1.

Trampas.
  • El texto de salida exacto: Negative feedback.
  • Una arista de v a v con peso negativo ya es un ciclo: el código la detecta sin caso especial.

Costo. O(n · m): 106 operaciones.

#include <bits/stdc++.h>
using namespace std;

const long long INF = LLONG_MAX / 2;

struct Arista { int u, v; long long w; };

/*
 * bellmanFord
 * Inputs: n -> cantidad de vertices (1..n); aristas -> lista dirigida;
 *         s -> fuente; dist -> donde se deja la distancia minima a cada vertice.
 * Return: true si existe un ciclo negativo alcanzable desde s.
 * Que hace: relaja todas las aristas hasta n veces. Sin ciclos negativos todo se
 *           estabiliza en a lo mas n - 1 pasadas, asi que si la pasada n todavia
 *           cambia algo, hay ciclo negativo. O(n * m).
 */
bool bellmanFord(int n, const vector<Arista>& aristas, int s, vector<long long>& dist){
    dist.assign(n + 1, INF);
    dist[s] = 0;

    for (int i = 1; i <= n; i++){
        bool cambio = false;
        for (const Arista& e : aristas){
            if (dist[e.u] != INF && dist[e.u] + e.w < dist[e.v]){
                dist[e.v] = dist[e.u] + e.w;
                cambio = true;
            }
        }
        if (!cambio) return false;
    }
    return true;
}

/*
 * main
 * Inputs (stdin): n y m, luego m lineas "u v w".
 * Return: 0
 * Que hace: corre Bellman-Ford desde 1 e imprime "Negative feedback" o las
 *           distancias a los usuarios 2..n separadas por espacios.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<Arista> aristas(m);
    for (int i = 0; i < m; i++) cin >> aristas[i].u >> aristas[i].v >> aristas[i].w;

    vector<long long> dist;
    if (bellmanFord(n, aristas, 1, dist)){
        cout << "Negative feedback\n";
        return 0;
    }

    for (int v = 2; v <= n; v++) cout << dist[v] << (v < n ? " " : "");
    cout << "\n";
    return 0;
}

 * Return: true si existe un ciclo negativo alcanzable desde s.
 * Que hace: relaja todas las aristas hasta n veces. Si la pasada n todavia
 *           cambia algo, hay ciclo negativo. O(n * m).
 */
bool bellmanFord(int n, const vector<Arista>& aristas, int s, vector<long long>& dist){
    dist.assign(n + 1, INF);
    dist[s] = 0;

    for (int i = 1; i <= n; i++){
        bool cambio = false;
        for (const Arista& e : aristas){
            if (dist[e.u] != INF && dist[e.u] + e.w < dist[e.v]){
                dist[e.v] = dist[e.u] + e.w;
                cambio = true;
            }
        }
        if (!cambio) return false;
    }
    return true;
}

/*
 * main
 * Inputs (stdin): n y m, luego m lineas "u v w".
 * Return: 0
 * Que hace: imprime "Bucle temporal." o las distancias a las islas 2..n.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<Arista> aristas(m);
    for (int i = 0; i < m; i++) cin >> aristas[i].u >> aristas[i].v >> aristas[i].w;

    vector<long long> dist;
    if (bellmanFord(n, aristas, 1, dist)){
        cout << "Bucle temporal.\n";
        return 0;
    }

    for (int v = 2; v <= n; v++) cout << dist[v] << (v < n ? " " : "");
    cout << "\n";
    return 0;
}

Torneo 2025-2 · I (no válido entonces)directo

Enunciado. Dos cadenas S y T del mismo largo (hasta 104), minúsculas. Hay K transmutaciones directas entre letras con costo, que se pueden encadenar. Costo mínimo de convertir S en T, posición a posición, o −1 si es imposible.

Cómo se reconoce. «Encadenar» sobre solo 26 elementos: todo par con Floyd-Warshall, una sola vez.

Idea. Grafo de 26 vértices. Floyd una vez (263 operaciones) y luego se suma d[Si][Ti] por posición. Correr un Dijkstra por cada posición sería un desperdicio.

Trampas.
  • Si Si = Ti el costo es 0: por eso d[i][i] = 0.
  • Se guarda el mínimo si una arista viene repetida.
  • La suma llega a 2,5 × 1011: long long.

Costo. O(263 + |S|).

#include <bits/stdc++.h>
using namespace std;

const long long INF = LLONG_MAX / 2;

/*
 * floyd
 * Inputs: d -> matriz con d[i][i] = 0, el costo de cada arista directa e INF si
 *         no existe.
 * Return: nada; deja en d la distancia minima entre todo par.
 * Que hace: el k del ciclo externo es el vertice que se permite usar como
 *           intermedio. Por eso k tiene que ir afuera. O(V^3).
 */
void floyd(vector<vector<long long>>& d){
    int n = d.size();
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (d[i][k] != INF && d[k][j] != INF)
                    d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}

/*
 * main
 * Inputs (stdin): S y T; K; luego K lineas "a b c".
 * Return: 0
 * Que hace: arma el grafo de 26 letras, corre Floyd una sola vez y suma el costo
 *           de cada posicion. Si alguna es imposible imprime -1.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s, t;
    int k;
    cin >> s >> t >> k;

    vector<vector<long long>> d(26, vector<long long>(26, INF));
    for (int i = 0; i < 26; i++) d[i][i] = 0;

    for (int i = 0; i < k; i++){
        char a, b;
        long long c;
        cin >> a >> b >> c;
        d[a - 'a'][b - 'a'] = min(d[a - 'a'][b - 'a'], c);
    }

    floyd(d);

    long long total = 0;
    for (int i = 0; i < (int)s.size(); i++){
        long long costo = d[s[i] - 'a'][t[i] - 'a'];
        if (costo == INF){
            cout << -1 << "\n";
            return 0;
        }
        total += costo;
    }

    cout << total << "\n";
    return 0;
}

Enunciado. n ≤ 100 criaturas y pociones que transforman una en otra (pueden repetirse). Encontrar el par (a, b) con más secuencias de exactamente x ≤ 100 pociones de a hasta b. Empates: menor a y luego menor b.

Cómo se reconoce. «Exactamente x pasos» en un grafo: Ax, porque [Ax]ab cuenta los caminos de x aristas.

Idea. Sea A[u][v] la cantidad de pociones de u a v. Un camino de x pasos es uno de x − 1 pasos más una arista final, y eso es justo multiplicar matrices. Con exponenciación por cuadrados son O(n3 log x). Con x ≤ 100 también alcanza multiplicar x veces, 108 operaciones, pero es más ajustado.

La línea i dice quién llega a i: por cada u leído se hace a[u][i]++, no al revés. Recorriendo a y b en orden creciente con > estricto, el primer máximo ya cumple el desempate.

Trampas.
  • Dirección de las aristas: la línea i lista los orígenes.
  • El PDF no da módulo: con un grafo denso y x = 100 el valor no cabe en 64 bits.

Costo. O(n3 log x).

#include <bits/stdc++.h>
using namespace std;

typedef vector<vector<long long>> Matriz;

/*
 * multiplicar
 * Inputs: a, b -> matrices cuadradas de n x n.
 * Return: el producto a * b. O(n^3).
 */
Matriz multiplicar(const Matriz& a, const Matriz& b){
    int n = a.size();
    Matriz c(n, vector<long long>(n, 0));

    for (int i = 0; i < n; i++)
        for (int k = 0; k < n; k++)
            if (a[i][k] != 0)
                for (int j = 0; j < n; j++)
                    c[i][j] += a[i][k] * b[k][j];
    return c;
}

/*
 * potencia
 * Inputs: base -> matriz de adyacencia; x -> exponente >= 1.
 * Return: base^x. Su celda [a][b] cuenta los caminos de exactamente x aristas.
 * Que hace: exponenciacion por cuadrados. O(n^3 log x).
 */
Matriz potencia(Matriz base, int x){
    Matriz r;
    bool hayR = false;

    while (x > 0){
        if (x & 1){
            r = hayR ? multiplicar(r, base) : base;
            hayR = true;
        }
        base = multiplicar(base, base);
        x >>= 1;
    }
    return r;
}

/*
 * main
 * Inputs (stdin): n y x; luego n lineas: la i-esima trae s y s criaturas que se
 *                 pueden transformar en i.
 * Return: 0
 * Que hace: arma la matriz A[u][i]++, la eleva a x y busca el maximo recorriendo
 *           a y b en orden creciente, asi el primer maximo ya es el del desempate.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, x;
    cin >> n >> x;

    Matriz a(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++){
        int s;
        cin >> s;
        for (int j = 0; j < s; j++){
            int u;
            cin >> u;
            a[u][i]++;
        }
    }

    Matriz p = potencia(a, x);

    int mejorA = 0, mejorB = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            if (p[i][j] > p[mejorA][mejorB]){
                mejorA = i;
                mejorB = j;
            }

    cout << mejorA << " " << mejorB << " " << p[mejorA][mejorB] << "\n";
    return 0;
}

C2 2025-1 · AmedioS1

Enunciado. n ≤ 106 pares (id, λ), con λ de hasta 6 decimales. Agrupar por λ en orden creciente e imprimir lambda: id1 id2 ..., con los ids crecientes, sin ceros de sobra pero con al menos un decimal.

Cómo se reconoce. El grafo y el flujo son pura historia: es ordenar y formatear.

Idea. Los decimales no se comparan bien, así que λ se convierte en un entero de millonésimas leyendo el texto, y 10.5 y 10.500 quedan iguales. Se ordena por (valor, id) y se agrupan los iguales.

Trampas.
  • No usar double como clave de agrupación.
  • 5.0, no 5 ni 5.000000.
  • n = 106: lectura rápida y \n.

Costo. O(n log n): 0,6 s con n = 106.

#include <bits/stdc++.h>
using namespace std;

/*
 * aMillonesimas
 * Inputs: s -> numero real como texto, con a lo mas 6 decimales.
 * Return: el numero multiplicado por 1e6, como entero exacto.
 * Que hace: arma el entero digito a digito y rellena con ceros hasta completar
 *           6 decimales. Asi 10.5 y 10.500 dan exactamente lo mismo.
 */
long long aMillonesimas(const string& s){
    long long valor = 0;
    int decimales = -1;

    for (char c : s){
        if (c == '.'){
            decimales = 0;
            continue;
        }
        valor = valor * 10 + (c - '0');
        if (decimales >= 0) decimales++;
    }

    if (decimales < 0) decimales = 0;
    for (; decimales < 6; decimales++) valor *= 10;
    return valor;
}

/*
 * formatear
 * Inputs: x -> valor en millonesimas.
 * Return: el numero como texto, sin ceros de sobra y con al menos un decimal.
 */
string formatear(long long x){
    string dec = to_string(x % 1000000);
    dec = string(6 - dec.size(), '0') + dec;
    while (dec.size() > 1 && dec.back() == '0') dec.pop_back();
    return to_string(x / 1000000) + "." + dec;
}

/*
 * main
 * Inputs (stdin): n, luego n lineas "id lambda".
 * Return: 0
 * Que hace: ordena por (lambda, id) y agrupa los lambda iguales. O(n log n).
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<pair<long long, int>> nodos(n);
    for (int i = 0; i < n; i++){
        string lambda;
        cin >> nodos[i].second >> lambda;
        nodos[i].first = aMillonesimas(lambda);
    }
    sort(nodos.begin(), nodos.end());

    for (int i = 0; i < n; ){
        cout << formatear(nodos[i].first) << ":";
        int j = i;
        for (; j < n && nodos[j].first == nodos[i].first; j++) cout << " " << nodos[j].second;
        cout << "\n";
        i = j;
    }
    return 0;
}

Fooling Around

Listado 3 · Adifícil

Enunciado. Alice y Bob sacan p − 1 piedras de un montón de N, con p primo. Gana quien saca la última. N ≤ 109. ¿Quién gana si ambos juegan óptimo?

Cómo se reconoce. Juego por turnos: una posición es ganadora si existe una jugada que deja al rival en una perdedora.

Idea. N es demasiado grande para recorrerlo en el juez, pero las posiciones perdedoras son muy pocas: 380 hasta 109. Se calculan una vez con un programa aparte y se pegan como tabla, y cada consulta es una búsqueda binaria.

El generador, por cada n, prueba las perdedoras l ya encontradas: n es ganadora si n − l + 1 es primo. Las separa por paridad: si p es un primo impar, n y l tienen la misma paridad, y el único caso distinto es p = 2 (sacar 1 piedra).

Trampas.
  • Calcular la tabla en cada ejecución tarda unos 17 s: va pegada en el código.
  • Sirve la idea general: si el espacio es enorme pero la respuesta tiene poca información, precalcula en tu computador.

Costo. O(log 380) por consulta.

#include <bits/stdc++.h>
using namespace std;

/*
 * Programa auxiliar: NO es lo que se sube al juez. Se corre una sola vez en el
 * computador (tarda menos de un minuto) y genera la tabla de posiciones
 * perdedoras que va pegada dentro de aFoolingAround.cpp.
 */

const long long LIMITE = 1000000000LL;

/*
 * cribaImpares
 * Inputs: hasta -> mayor numero que se quiere poder consultar.
 * Return: vector compuesto donde compuesto[i] es true si el impar 2*i+1 NO es
 *         primo.
 * Que hace: criba de Eratostenes guardando solo los impares (los pares mayores
 *           que 2 nunca son primos), asi la tabla para 1e9 ocupa 5e8 bits,
 *           unos 62 MB, en vez del doble.
 */
vector<bool> cribaImpares(long long hasta){
    vector<bool> compuesto(hasta / 2 + 1, false);
    for (long long i = 3; i * i <= hasta; i += 2){
        if (!compuesto[i / 2]){
            for (long long j = i * i; j <= hasta; j += 2 * i){
                compuesto[j / 2] = true;
            }
        }
    }
    return compuesto;
}

/*
 * esPrimo
 * Inputs: x -> numero a revisar; compuesto -> la criba de cribaImpares.
 * Return: true si x es primo.
 * Que hace: el 2 se revisa aparte; para el resto basta con que sea impar y
 *           que la criba no lo haya marcado.
 */
bool esPrimo(long long x, const vector<bool>& compuesto){
    if (x == 2) return true;
    if (x < 2 || x % 2 == 0) return false;
    return !compuesto[x / 2];
}

/*
 * posicionesPerdedoras
 * Inputs: limite -> mayor N que puede aparecer en la entrada.
 * Return: vector ordenado con todos los n <= limite desde los que el jugador
 *         que mueve pierde (posiciones P).
 * Que hace: recorre n = 0, 1, 2, ...
 */
vector<long long> posicionesPerdedoras(long long limite){
    vector<bool> compuesto = cribaImpares(limite + 1);
    vector<long long> perdedorasPorParidad[2];
    vector<long long> todas;

    for (long long n = 0; n <= limite; n++){
        bool gana = !todas.empty() && todas.back() == n - 1;

        for (int i = 0; !gana && i < (int)perdedorasPorParidad[n % 2].size(); i++){
            long long l = perdedorasPorParidad[n % 2][i];
            if (esPrimo(n - l + 1, compuesto)) gana = true;
        }

        if (!gana){
            perdedorasPorParidad[n % 2].push_back(n);
            todas.push_back(n);
        }
    }

    return todas;
}

using namespace std;

/*
 * PERDEDORAS: todas las posiciones n entre 0 y 1e9 desde las que el jugador
 * que mueve pierde si el rival juega perfecto. Son solo 380 y estan ordenadas.
 * Se calcularon una vez con aFoolingAroundGenerador.cpp, porque recalcularlas
 * hasta 1e9 en cada ejecucion tardaria unos 17 segundos y el juez no da tanto.
 */
const int CANTIDAD_PERDEDORAS = 380;
const int PERDEDORAS[CANTIDAD_PERDEDORAS] = {
    0, 3, 8, 11, 32, 35, 56, 59, /* ... 380 valores ... */ 916215504, 978364209

/*
 * ganador
 * Inputs: n -> cantidad de piedras con que parte el juego (1 <= n <= 1e9).

string ganador(int n){
    if (binary_search(PERDEDORAS, PERDEDORAS + CANTIDAD_PERDEDORAS, n)) return "Bob";

N-Puzzle

Listado 3 · Bdirecto

Enunciado. Tablero 4 × 4 con letras A a O y un hueco. Calcular la suma de distancias Manhattan de cada letra a su casilla final.

Idea. La letra A + k va en la fila k / 4 y la columna k % 4.

Trampas.

#include <bits/stdc++.h>
using namespace std;

const int LADO = 4;

/*
 * distanciaFicha
 * Inputs: ficha -> letra entre 'A' y 'O'.
 *         fila, columna -> posicion actual de la ficha en el tablero (0 a 3).
 * Return: distancia Manhattan entre la posicion actual y la posicion que le
 *         corresponde en el tablero ordenado.
 * Que hace: la ficha 'A' + k va en la casilla k del tablero recorrido por
 *           filas, asi que su fila objetivo es k / 4 y su columna k % 4.
 */
int distanciaFicha(char ficha, int fila, int columna){
    int k = ficha - 'A';
    return abs(fila - k / LADO) + abs(columna - k % LADO);
}

/*
 * scatter
 * Inputs: tablero -> arreglo de 4 strings de largo 4 con el estado del puzzle.
 * Return: suma de las distancias Manhattan de cada ficha a su posicion final.
 * Que hace: recorre las 16 casillas y suma la distancia de cada letra,
 *           ignorando el '.' porque es el hueco y no cuenta como ficha.
 */
int scatter(const string tablero[LADO]){
    int total = 0;
    for (int fila = 0; fila < LADO; fila++){
        for (int columna = 0; columna < LADO; columna++){
            char ficha = tablero[fila][columna];
            if (ficha != '.'){
                total += distanciaFicha(ficha, fila, columna);
            }
        }
    }
    return total;
}

#include <bits/stdc++.h>
using namespace std;

/*
 * minusculas
 * Inputs: s -> texto.
 * Return: el texto en minusculas.
 */
string minusculas(string s){

/*
 * reemplazarJose
 * Inputs: s -> texto en minusculas.

string reemplazarJose(const string& s){
    string r;

            i += 4;
        } else {
            r += s[i++];
        }
    }
    return r;
}

SETeando Colores

Torneo 2025-2 · H (no válido entonces)difícil

Enunciado. Grilla n × m (hasta 2500) de colores. Las operaciones pintan una fila o una columna de un color. Decidir si la grilla se puede obtener y dar a lo más n + m operaciones.

Cómo se reconoce. Las pinturas se sobreescriben: se piensa al revés.

Idea. La última pintura deja una línea de un solo color. Se retira esa línea (sus celdas ya no importan, cualquier cosa anterior queda tapada) y se repite con las líneas que queden de un solo color. Si al final queda alguna celda sin cubrir, es NO. Las operaciones se imprimen en orden inverso al de retiro.

Saber si una línea quedó de un solo color se hace con dos punteros por línea: p es la primera celda viva y q la primera viva de color distinto. Ninguno retrocede, así que el total es O(n · m).

Trampas.
  • Una línea sin celdas vivas no se pinta.
  • Puede haber varias respuestas válidas.

Costo. O(n · m): 0,63 s con 2500 × 2500.

#include <bits/stdc++.h>
using namespace std;

struct Pintado {
    int n, m;
    vector<int> g;
    vector<char> usada;
    vector<int> p, q;

    int largo(int L) const { return L < n ? m : n; }
    int cruce(int L, int k) const { return L < n ? n + k : k; }
    int color(int L, int k) const { return L < n ? g[L * m + k] : g[k * m + (L - n)]; }
    bool viva(int L, int k) const { return !usada[cruce(L, k)]; }

    /*
     * avanzar
     * Inputs: L -> linea (fila si L < n, columna si no).
     * Return: true si la linea quedo de un solo color entre sus celdas vivas.
     * Que hace: p es la primera celda viva y q la primera viva despues de p con
     *           color distinto. Ninguno retrocede: entre p y q todo es muerto o
     *           del color de p, asi el trabajo total por linea es O(su largo).
     */
    bool avanzar(int L){
        int len = largo(L);
        while (p[L] < len && !viva(L, p[L])) p[L]++;
        q[L] = max(q[L], p[L] + 1);
        while (q[L] < len && (!viva(L, q[L]) || color(L, q[L]) == color(L, p[L]))) q[L]++;
        return q[L] >= len;
    }
};

/*
 * resolver
 * Inputs: pintado -> estructura con la grilla cargada; ops -> salida.
 * Return: true si la grilla se puede imprimir; deja en ops las operaciones
 *         (tipo, indice, color) en el orden en que hay que ejecutarlas.
 * Que hace: piensa al reves. La ultima pintura deja una linea de un solo color;
 *           se retira esa linea (sus celdas ya no importan) y se repite con las
 *           que queden de un solo color. Se usa una cola de lineas monocromas.
 */
bool resolver(Pintado& t, vector<array<int, 3>>& ops){
    int n = t.n, m = t.m, total = n + m;
    t.usada.assign(total, 0);
    t.p.assign(total, 0);
    t.q.assign(total, 0);

    queue<int> cola;
    for (int L = 0; L < total; L++)
        if (t.avanzar(L)) cola.push(L);

    while (!cola.empty()){
        int L = cola.front();
        cola.pop();
        if (t.usada[L] || t.p[L] >= t.largo(L)) continue;

        bool esFila = L < n;
        ops.push_back({esFila ? 1 : 2, (esFila ? L : L - n) + 1, t.color(L, t.p[L])});
        t.usada[L] = 1;

        int desde = esFila ? n : 0, hasta = esFila ? total : n;
        for (int X = desde; X < hasta; X++){
            if (t.usada[X]) continue;
            bool yaEra = t.q[X] >= t.largo(X);
            if (t.avanzar(X) && !yaEra) cola.push(X);
        }
    }

    for (int i = 0; i < n; i++)
        if (!t.usada[i] && t.p[i] < m) return false;

    reverse(ops.begin(), ops.end());
    return true;
}

    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int casos;
    cin >> casos;

    while (casos--){
        int n, m, c;
        cin >> n >> m >> c;

        Pintado t;
        t.n = n;
        t.m = m;
        t.g.resize(n * m);

        vector<array<int, 3>> ops;

        for (auto& o : ops) cout << o[0] << " " << o[1] << " " << o[2] << "\n";
    }
    return 0;
}

Enunciado. Programa de comandos R (invertir) y D (borrar el primero) sobre una lista de hasta 105 enteros, hasta 100 casos. Imprimir la lista final, o error si se borra de una lista vacía.

Cómo se reconoce. Invertir de verdad cuesta O(n) por comando: hay que simular sin mover nada.

Idea. Dos índices, izq y der, delimitan la parte viva, y un booleano dice si está invertida. R solo cambia el booleano y D avanza el extremo que corresponda. Cada comando cuesta O(1).

Trampas.

  • La entrada viene como texto [1,2,3]: hay que parsearla.

#include <bits/stdc++.h>
using namespace std;

/*
  parsearLista
  Inputs:
    - texto: la lista tal como viene en la entrada, con formato "[1,2,3]" (sin espacios).
  Return:
    - vector<int> con los enteros del texto, en el mismo orden.
  Que hace:
    Recorre el texto ignorando corchetes y comas, y arma cada numero digito a
    digito.
*/
vector<int> parsearLista(const string &texto){
    vector<int> numeros;
    long long actual = 0;
    bool leyendo = false;

    for (char c : texto){
        if (c >= '0' && c <= '9'){
            actual = actual * 10 + (c - '0');
            leyendo = true;
        } else if (leyendo){
            numeros.push_back((int)actual);
            actual = 0;
            leyendo = false;
        }
    }

    if (leyendo){
        numeros.push_back((int)actual);
    }

    return numeros;
}

/*
  aplicarPrograma
  Inputs:
    - programa: secuencia de comandos 'R' (invertir) y 'D' (borrar el primero).
    - lista: los enteros iniciales, en orden.
  Return:
    - string con la lista final en formato "[a,b,c]", o "error" si en algun
      momento se intento borrar de una lista vacia.
  Que hace:
    Simula el programa sin invertir nunca la lista de verdad.
*/
string aplicarPrograma(const string &programa, const vector<int> &lista){
    int izq = 0;
    int der = (int)lista.size() - 1;
    bool invertida = false;

    for (char c : programa){
        if (c == 'R'){
            invertida = !invertida;
        } else {
            if (izq > der){
                return "error";
            }
            if (invertida){
                der--;
            } else {
                izq++;
            }
        }
    }

    int vivos = der - izq + 1;
    string salida;
    salida.reserve(2 + vivos * 8);
    salida.push_back('[');

    if (invertida){
        for (int i = der; i >= izq; i--){
            if (i != der){
                salida.push_back(',');
            }
            salida += to_string(lista[i]);
        }
    } else {
        for (int i = izq; i <= der; i++){
            if (i != izq){
                salida.push_back(',');
            }
            salida += to_string(lista[i]);
        }
    }

    salida.push_back(']');
    return salida;
}

        }

        salida.push_back(ch[i]);

Bungee Builder

Listado 1 · Bdifícil

Enunciado. N ≤ 106 montañas. Un puente une dos montañas, a altura máxima igual a la menor de las dos, y debe quedar estrictamente sobre todas las que hay entre ellas. Maximizar la altura del puente menos la montaña más baja bajo él; 0 si no se puede.

Cómo se reconoce. Pares que «se ven» entre sí con N = 106: pila monótona.

Idea. Un par es válido si todo lo que hay entre ambas montañas es más bajo que las dos. Esos pares son O(N) y salen con una pila decreciente: al llegar h[j] se desapilan las ≤ h[j], y cada una forma un par válido con j, igual que la que queda en el tope. Junto a cada elemento de la pila se guarda el mínimo del tramo que le sigue, y al desapilar se va acumulando. El valor del par es la menor de sus dos alturas menos el mínimo del tramo.

Trampas.
  • Montañas adyacentes no tienen tramo interior y no cuentan: por eso el INF.
  • Alturas iguales: el booleano tapado evita contar un par que ya no ve.

Costo. O(N).

#include <bits/stdc++.h>
using namespace std;

const int INF = 2000000000;

int main(){
    int n;

    ios::sync_with_stdio(false);
    cin.tie(NULL);

    cin >> n;

    vector<int> h(n);
    for (int i = 0; i < n; i++){
        cin >> h[i];
    }

    vector<int> pila;
    vector<int> minTramo;
    long long mejor = 0;

    for (int j = 0; j < n; j++){
        int acumulado = INF;
        bool tapado = false;

        while (!pila.empty() && pila.back() <= h[j]){
            int alto = pila.back();
            int medio = min(acumulado, minTramo.back());

            pila.pop_back();
            minTramo.pop_back();

            if (medio != INF){
                mejor = max(mejor, (long long)min(alto, h[j]) - medio);
            }

            acumulado = min(medio, alto);
            tapado = (alto == h[j]);
        }

        if (!pila.empty()){
            if (!tapado){
                int medio = min(acumulado, minTramo.back());

                if (medio != INF){
                    mejor = max(mejor, (long long)min(pila.back(), h[j]) - medio);
                }
            }

            minTramo.back() = min(minTramo.back(), acumulado);
        }

        pila.push_back(h[j]);
        minTramo.push_back(INF);
    }

    cout << mejor << "\n";

    return 0;
}

Listado 1 · Emedio

Enunciado. Órdenes buy x shares at y y sell x shares at y. Hay trato cuando la mejor compra es ≥ la mejor venta, al precio de la venta. Tras cada orden imprimir ask, bid y último precio, con - si no existe.

Cómo se reconoce. Siempre interesa el mejor de cada lado: dos heaps.

Idea. Un max-heap de compras y un min-heap de ventas. Después de cada orden, mientras bid >= ask, se transa el mínimo de ambas cantidades y lo que sobra vuelve a su heap.

Trampas.
  • El precio del trato es el ask, no el bid.
  • Una orden puede generar varios tratos: va en un while.

Costo. O(n log n) por caso.

#include <bits/stdc++.h>
using namespace std;

typedef pair<int,int> Orden;
typedef priority_queue<Orden> LibroCompras;
typedef priority_queue<Orden, vector<Orden>, greater<Orden> > LibroVentas;

/*
 * procesarCaso
 * Inputs: n (1 <= n <= 1000), la cantidad de ordenes del caso; las n ordenes
 *         se leen desde stdin con el formato "tipo x shares at y", donde tipo
 *         es "buy" o "sell", x la cantidad de acciones e y el precio.
 * Return: void (imprime n lineas de la forma "ask bid stock" en stdout).
 * Que hace: mantiene el libro de ordenes en dos heaps, uno de compras
 *           ordenado por precio maximo (bid) y otro de ventas ordenado por
 *           precio minimo (ask).
 */
void procesarCaso(int n){
    LibroCompras compras;
    LibroVentas ventas;

    int stock = 0;
    bool hayStock = false;

    for (int i = 0; i < n; i++){
        string tipo, palabra;
        int cantidad, precio;
        cin >> tipo >> cantidad >> palabra >> palabra >> precio;

        if (tipo == "buy") compras.push(make_pair(precio, cantidad));
        else ventas.push(make_pair(precio, cantidad));

        while (!compras.empty() && !ventas.empty() && compras.top().first >= ventas.top().first){
            Orden compra = compras.top();
            Orden venta = ventas.top();
            compras.pop();
            ventas.pop();

            int transadas = min(compra.second, venta.second);
            stock = venta.first;
            hayStock = true;

            compra.second -= transadas;
            venta.second -= transadas;

            if (compra.second > 0) compras.push(compra);
            if (venta.second > 0) ventas.push(venta);
        }

        if (ventas.empty()) cout << "-";
        else cout << ventas.top().first;
        cout << " ";

        if (compras.empty()) cout << "-";
        else cout << compras.top().first;
        cout << " ";

        if (hayStock) cout << stock;
        else cout << "-";
        cout << "\n";
    }
}

        }
        total += (int)fila.size() - pos;

    }

    return total;
}

A Classy Problem

Listado 2 · Cmedio

Enunciado. Personas con clases tipo upper-upper-lower-middle, donde la última palabra manda y las anteriores refinan. Si falta detalle se asume middle. Ordenar de mayor a menor; en empate, alfabético.

Cómo se reconoce. Orden con criterio propio: comparador.

Idea. Se invierten las palabras (la más importante queda primero) y se rellena con middle hasta largo 10, así dos clases equivalentes quedan idénticas. Los vectores se comparan lexicográficamente.

Trampas.
  • El nombre viene con : y hay que quitárselo.
  • 30 signos = después de cada caso.

Costo. O(n log n) por caso.

#include <bits/stdc++.h>
using namespace std;

const int NIVELES = 10;

struct Persona {
    string nombre;
    vector<int> clave;
};

/*
 * valorPalabra
 * Inputs: palabra -> una de las tres palabras de clase: "upper", "middle" o
 *         "lower".
 * Return: 2 para upper, 1 para middle y 0 para lower.
 * Que hace: traduce la palabra a un numero para poder comparar clases con los
 *           operadores normales de orden.
 */
int valorPalabra(const string& palabra){
    if (palabra == "upper") return 2;
    if (palabra == "middle") return 1;
    return 0;
}

/*
 * clavePorClase
 * Inputs: clase -> string con la clase tal como viene en la entrada, del tipo
 *         "upper-upper-lower-middle" (hasta 10 palabras unidas por guiones).
 * Return: vector de largo 10 que describe la clase desde el nivel mas general
 *         al mas especifico, rellenado con middle (1) donde ya no hay detalle.
 * Que hace: separa la clase por guiones y la invierte, porque la ultima
 *           palabra es la clase principal y las anteriores son refinamientos
 *           cada vez mas finos.
 */
vector<int> clavePorClase(const string& clase){
    vector<string> palabras;
    string actual;

    for (char c : clase){
        if (c == '-'){
            palabras.push_back(actual);
            actual.clear();
        } else {
            actual += c;
        }
    }
    palabras.push_back(actual);

    vector<int> clave(NIVELES, 1);
    for (int i = 0; i < (int)palabras.size(); i++){
        clave[i] = valorPalabra(palabras[palabras.size() - 1 - i]);
    }

    return clave;
}

/*
 * masClassy
 * Inputs: a, b -> dos personas ya con su clave de clase calculada.
 * Return: true si "a" debe ir antes que "b" en la salida.
 * Que hace: comparador para el sort.
 */
bool masClassy(const Persona& a, const Persona& b){
    if (a.clave != b.clave){
        return a.clave > b.clave;
    }
    return a.nombre < b.nombre;
}

L2·F

Firefly

Listado 2 · Fmedio

Enunciado. Cueva de alto H ≤ 5 × 105 con N ≤ 2 × 105 obstáculos alternados desde el piso y el techo. Hallar el menor número de obstáculos que se rompen volando a una altura fija, y cuántas alturas lo logran.

Cómo se reconoce. Contar cuántos intervalos cubren cada nivel: suma acumulada.

Idea. Una estalagmita de tamaño s tapa los niveles 1..s, y una estalactita, H − s + 1..H. Con un histograma por tipo y sumas de sufijo sale la cuenta de todos los niveles en una pasada.

Trampas.
  • Simular nivel por nivel es O(N · H): no alcanza.

Costo. O(N + H).

#include <bits/stdc++.h>
using namespace std;

/*
 * contarPorAltura
 * Inputs: n y h (largo y alto de la cueva), y el vector tamanos con los n
 *         tamanos de los obstaculos en el orden en que aparecen (el primero es
 *         una estalagmita y desde ahi se van alternando).
 * Return: un vector destruidos de tamano h+1, donde destruidos[k] es la
 *         cantidad de obstaculos que la luciernaga rompe si vuela por el nivel
 *         k (los niveles validos van de 1 a h).
 * Que hace: en vez de simular nivel por nivel (que seria O(n*h)), arma dos
 *           histogramas.
 */
vector<int> contarPorAltura(int n, int h, const vector<int>& tamanos){
    vector<int> piso(h + 2, 0);
    vector<int> techo(h + 2, 0);

    for (int i = 0; i < n; i++){
        if (i % 2 == 0) piso[tamanos[i]]++;
        else techo[tamanos[i]]++;
    }

    for (int s = h; s >= 1; s--){
        piso[s] += piso[s + 1];
        techo[s] += techo[s + 1];
    }

    vector<int> destruidos(h + 1, 0);
    for (int k = 1; k <= h; k++){
        destruidos[k] = piso[k] + techo[h - k + 1];
    }

    return destruidos;
}

Room Painting

Listado 2 · Gdirecto

Enunciado. Tamaños de tarro disponibles y cantidad necesaria por color. Por cada color se compra el tarro más chico que alcance. Sumar lo que sobra.

Cómo se reconoce. «El más chico que sea ≥ x»: búsqueda binaria.

Idea. Se ordenan los tarros una vez y se busca por cada color. lower_bound hace lo mismo que la búsqueda escrita a mano.

Trampas.
  • La suma llega a 105 × 109: long long.

Costo. O((n + m) log n).

#include <bits/stdc++.h>
using namespace std;

/*
 * menorTarroQueAlcanza
 * Inputs: tarros -> vector con los tamanos de tarro que vende la tienda, YA
 *         ordenados de menor a mayor; necesita -> cuantos microlitros hace
 *         falta de un color.
 * Return: el tamano del tarro mas chico que es mayor o igual a necesita. El
 *         enunciado garantiza que siempre existe uno.
 * Que hace: busqueda binaria sobre el vector ordenado.
 */
int menorTarroQueAlcanza(const vector<int>& tarros, int necesita){
    int izq = 0;
    int der = (int)tarros.size() - 1;
    int respuesta = tarros[der];

    while (izq <= der){
        int medio = izq + (der - izq) / 2;

        if (tarros[medio] >= necesita){
            respuesta = tarros[medio];
            der = medio - 1;
        } else {
            izq = medio + 1;
        }
    }

    return respuesta;
}

/*
 * pinturaDesperdiciada
 * Inputs: tarros -> tamanos de tarro que ofrece la tienda (se ordena adentro);
 *         necesidades -> cuantos microlitros necesita Joe de cada color.
 * Return: el total de microlitros que sobran si para cada color compra el
 *         tarro mas chico que le alcanza.
 * Que hace: como los colores son independientes entre si (un tarro por color,
 *           pintura ilimitada de cada uno), minimizar el desperdicio total es
 *           lo mismo que minimizarlo color por color.
 */
long long pinturaDesperdiciada(vector<int>& tarros, const vector<int>& necesidades){
    sort(tarros.begin(), tarros.end());

    long long total = 0;
    for (int i = 0; i < (int)necesidades.size(); i++){
        int tarro = menorTarroQueAlcanza(tarros, necesidades[i]);
        total += (long long)(tarro - necesidades[i]);
    }

    return total;
}

Synchronizing Lists

Listado 2 · Hdirecto

Enunciado. Dos listas sin repetidos. El k-ésimo menor de la primera corresponde al k-ésimo menor de la segunda. Reordenar la segunda según la primera.

Cómo se reconoce. Correspondencia por rango: ordenar copias y buscar.

Idea. Se ordenan copias de ambas. El rango de cada elemento de la primera sale con lower_bound, y ese rango da su pareja en la segunda ordenada.

Trampas.
  • Línea en blanco entre casos.

Costo. O(n log n).

#include <bits/stdc++.h>
using namespace std;

/*
 * sincronizarListas
 * Inputs: lista1 -> primera lista en el orden fijo en que fue leida;
 *         lista2 -> segunda lista, que viene desordenada respecto a la primera.
 * Return: un vector con los numeros de lista2 reordenados de modo que la
 *         posicion i tenga el numero que le corresponde a lista1[i].
 * Que hace: la correspondencia del enunciado es por posicion una vez que
 *           ambas listas estan ordenadas.
 */
vector<int> sincronizarListas(const vector<int>& lista1, const vector<int>& lista2){
    int n = (int)lista1.size();

    vector<int> ordenada1 = lista1;
    vector<int> ordenada2 = lista2;
    sort(ordenada1.begin(), ordenada1.end());
    sort(ordenada2.begin(), ordenada2.end());

    vector<int> resultado(n);
    for (int i = 0; i < n; i++){
        int rango = (int)(lower_bound(ordenada1.begin(), ordenada1.end(), lista1[i]) - ordenada1.begin());
        resultado[i] = ordenada2[rango];
    }

    return resultado;
}
