Ejercicios por día, con pistas para armar el código sin ver la solución.

Cada día tiene pocos ejercicios, elegidos por lo que más sale. Si un día no alcanzas, haz solo los marcados Indispensable.

Las pistas se abren de a una y parten con preguntas. La penúltima es una plantilla con huecos: lo más parecido a tener el formulario al lado, sin ver la respuesta. Ningún ejercicio trae su solución en esta página.

Cómo trabajar cada ejercicio

Intenta primero 10 minutos sin pistas (30 en los simulacros), siguiendo esta rutina, que es la misma del certamen:

  1. Tamaño: ¿cuánto vale n? ¿Qué costo cabe en un segundo?
  2. Pregunta: ¿piden máximo, mínimo, contar o decidir?
  3. Familia: ¿a qué problema conocido se parece?
  4. Núcleo: ¿qué guardo, o con qué criterio ordeno?
  5. Código: lectura, inicialización, núcleo e impresión.
  6. Prueba: ejemplos, un caso chico y los tipos de datos.

Después abre una pista a la vez. Si llegaste a la plantilla con huecos, el ejercicio volverá a aparecer en el repaso del viernes 27.

Indispensable25 min tema muy alta

Ejercicio propio, basado en las clases 16 y 17. Este criterio salió en dos de los últimos tres certámenes y es el voraz que se demuestra en clases.

Una máquina ejecuta n tareas, una a la vez y sin pausas. La tarea j dura lj y tiene peso wj. Si Cj es el instante en que termina, hay que minimizar la suma de wj · Cj.

  1. Pista 1 · Qué familia es

    n = 105 descarta probar los n! órdenes. Te piden el mejor orden, así que piensa en ordenar con algún criterio y simular una sola vez. Es un voraz.

  2. Pista 2 · Dos casos extremos

    Si todas duran lo mismo, ¿cuáles pondrías primero? Si todas pesan lo mismo, ¿cuáles? Responde en papel antes de seguir. El criterio general tiene que respetar las dos respuestas.

  3. Pista 3 · Buscar el criterio

    A igual largo, primero el de mayor peso; a igual peso, primero el más corto. Hay dos candidatos naturales: w − l y w / l. Calcula ambos a mano con el ejemplo 2. Solo uno da 22.

  4. Pista 4 · Comparar sin decimales

    El criterio correcto es w / l, de mayor a menor. Para decidir si a va antes que b no dividas: la desigualdad wa / la > wb / lb, con largos positivos, se puede escribir sin divisiones. Hazlo en papel.

  5. Pista 5 · Cómo armar el programa

    Un struct con l y w. Una función que devuelve true si a va antes que b. Leer, ordenar con esa función, y recorrer con dos variables: el reloj y el costo acumulado.

Listado 4 · A. Es el patrón de emparejar dos listas, que se repite en varios voraces. Ya lo resolviste: hazlo sin mirar tu código.

Hay n tareas con su duración y m intervalos de silencio con su largo. Cada intervalo admite a lo más una tarea, que debe caber completa (t ≤ ℓ). Maximizar las tareas terminadas.

  1. Pista 1 · Qué familia es

    Dos listas y hay que formar parejas. Con estos tamaños, lo natural es ordenar las dos.

  2. Pista 2 · Por dónde partir

    Recorre los intervalos de menor a mayor. A cada uno, ¿qué tarea le conviene dar, si es que alguna?

  3. Pista 3 · La decisión

    La tarea más corta que quede. Si esa no cabe, ninguna otra cabe y el intervalo se queda vacío. Si cabe, darle justo esa no perjudica: las largas quedan para los intervalos grandes.

  4. Pista 4 · Dos punteros

    Basta un índice con la tarea más corta que queda, que avanza solo cuando se forma una pareja, y un ciclo sobre los intervalos.

/*
 * maximoDeTareas
 * Inputs: tareas, intervalos -> duraciones (se ordenan aqui).

 * Que hace: a cada intervalo, de menor a mayor, le da la tarea mas corta que quede.

int maximoDeTareas(vector<int>& tareas, vector<int>& intervalos){
    sort(tareas.begin(), tareas.end());
    sort(intervalos.begin(), intervalos.end());

    int hechas = 0;
    for (int j = 0; j < (int)intervalos.size() && 1; j++)
        if (2) hechas++;

    return 3;
}

/*
 * main
 * Inputs (stdin): n, m y las dos listas.
 * Return: 0
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<int> tareas(n), intervalos(m);
    for (int i = 0; i < n; i++) cin >> tareas[i];
    for (int j = 0; j < m; j++) cin >> intervalos[j];

    cout << maximoDeTareas(tareas, intervalos) << "\n";
    return 0;
}

T24·B

Escaleras para salvar el ramo

Indispensable20 min tema muy alta

Torneo 2024-2 · B. La PD lineal salió en tres de los cuatro certámenes. Este es el mejor ejercicio para fijar el método.

Una escalera de n peldaños, cada uno con una penalización. Se parte en el primero, se termina en el último, y cada salto avanza 1, 2 o 3 peldaños. Se empieza con 1000 puntos y al pisar un peldaño se descuenta su penalización. Maximizar el puntaje final.

Entrada. n (1 ≤ n ≤ 105). Luego n enteros pi (0 ≤ pi ≤ 500).

Salida. El máximo puntaje al llegar al último peldaño.

Entrada 1
1
100
Salida 1
900
Entrada 2
3
0 0 0
Salida 2
1000
Entrada 3
4
5 10 15 20
Salida 3
975
  1. Pista 1 · Qué familia es

    Decisiones en línea, y n = 105 pide algo O(n). Probar todos los saltos sería exponencial: es PD lineal.

  2. Pista 2 · Qué guardar

    Define A[i] con una frase completa. Pregúntate qué necesitas saber de i para decidir cómo seguir. Maximizar 1000 menos lo descontado es lo mismo que minimizar lo descontado.

  3. Pista 3 · La definición

    A[i] es la menor penalización total para llegar pisando el peldaño i.

  4. Pista 4 · La última decisión

    ¿Desde qué peldaños pudiste saltar a i? Son como máximo tres. Lo que se paga al llegar a i es siempre pi.

  5. Pista 5 · Caso base y respuesta

    El primer peldaño se pisa siempre. Cuidado con los índices: para i chico no existen los tres anteriores. La respuesta sale de la última celda.

    Lo más parecido a tener el formulario al lado. Copia la estructura en tu editor y completa cada hueco.

 * Inputs (stdin): n y las n penalizaciones.

 * Que hace: A[i] es la menor penalizacion para llegar pisando el peldano i.

    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

        long long mejor = 2;
        if (i >= 2) mejor = min(mejor, 3);

        A[i] = 5;
    }

    cout << 6 << "\n";
    return 0;
}

    4. Cuándo existe el peldaño tres atrás.
    5. Lo mejor de los anteriores más lo que se paga aquí.
    6. Los puntos iniciales menos lo descontado.

Distancia de edición

Indispensable35 min tema alta

Ejercicio propio, tema de la ayudantía del 7 de noviembre. El alineamiento tiene clase y ayudantía, y salió en el último certamen.

Dadas dos palabras x e y, convertir x en y con la menor cantidad de operaciones. Se puede insertar una letra, borrar una letra o reemplazar una letra por otra, y cada operación cuesta 1.

Entrada. Dos líneas con x e y (minúsculas, largo entre 1 y 2000).

Salida. La menor cantidad de operaciones.

Entrada 1
kitten
sitting
Salida 1
3
Entrada 2
flaw
lawn
Salida 2
2
  1. Pista 1 · Qué familia es

    Dos secuencias que se comparan en orden, con operaciones que tienen costo: alineamiento de secuencias. Aquí un espacio cuesta 1 y enfrentar letras distintas cuesta 1.

  2. Pista 2 · Qué guardar

    Hay dos prefijos en juego, así que hacen falta dos índices. Define A[i][j] con una frase.

  3. Pista 3 · La última columna

    A[i][j] es el costo mínimo de igualar los primeros i de x con los primeros j de y. La última columna solo puede ser: xi enfrentada a yj, xi frente a un espacio, o yj frente a un espacio. ¿Qué prefijos quedan en cada caso?

  4. Pista 4 · Casos base

    ¿Cuánto cuesta igualar i letras con una palabra vacía? ¿Y una palabra vacía con j letras?

  5. Pista 5 · Orden de llenado

    A[i][j] necesita la celda de arriba, la de la izquierda y la diagonal. Dos ciclos crecientes bastan. La fila i usa la letra x[i - 1], porque el string parte en 0.

  6. Pista 6 · Plantilla con huecos

    Lo más parecido a tener el formulario al lado. Copia la estructura en tu editor y completa cada hueco.

    #include <bits/stdc++.h>
using namespace std;

/*
 * distancia
 * Inputs: x, y -> las dos palabras.
 * Return: minima cantidad de operaciones.
 * Que hace: llena la tabla de prefijos.
 */
int distancia(const string& x, const string& y){
    int m = x.size(), n = y.size();
    vector<vector<int>> A(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) A[i][0] = 1;
    for (int j = 1; j <= n; j++) A[0][j] = 2;

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            A[i][j] = min({3,
                           4,
                           5});
    return 6;
}

/*
 * main
 * Inputs (stdin): las dos palabras.
 * Return: 0
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string x, y;
    cin >> x >> y;

    cout << distancia(x, y) << "\n";
    return 0;
}
  7. Pista 7 · Qué va en cada hueco
    1. Borrar las i letras.
    2. Insertar las j letras.
    3. Enfrentar las dos últimas letras: cuesta 0 si son iguales y 1 si no.
    4. xi frente a un espacio.
    5. yj frente a un espacio.
    6. La celda con todo x y todo y.
Antes de enviar: revisa
  • La tabla mide (m + 1) × (n + 1).
  • Letras en x[i - 1] e y[j - 1], no en x[i].

Si te sobra tiempo25 min tema media

Torneo 2024-2 · J. Enseña a simplificar una condición antes de programar. No es del temario central.

Una calle de baldosas con una letra cada una (cadena S). Desde la baldosa i puedes avanzar a i + 1 con costo 1, o saltar gratis a una baldosa j > i si existe un substring de largo k (1 ≤ k ≤ n) que empieza en i idéntico a uno que empieza en j. Hallar el costo mínimo de la primera a la última.

Entrada. Una línea con S, de minúsculas, largo hasta 105.

Salida. El costo mínimo.

Entrada 1
holacomoestashk
Salida 1
1
Entrada 2
pandateodio
Salida 2
4
  1. Pista 1 · Simplifica la condición

    El largo k lo eliges tú. ¿Cuál es el k más fácil de satisfacer? ¿Qué queda de la condición entonces?

  2. Pista 2 · La condición real

    Con k = 1 basta: se puede saltar de i a j si S[i] = S[j].

  3. Pista 3 · Qué guardar

    A[j] es el costo mínimo de llegar a j: venir de j − 1 pagando 1, o saltar gratis desde alguna baldosa anterior con la misma letra.

  4. Pista 4 · Hacerlo en O(n)

    Mirar todas las baldosas anteriores es O(n2). Por cada letra basta recordar el menor costo con el que se ha llegado a ella.

  5. Pista 5 · Plantilla con huecos

    Lo más parecido a tener el formulario al lado. Copia la estructura en tu editor y completa cada hueco.

    #include <bits/stdc++.h>
using namespace std;

/*
 * main
 * Inputs (stdin): la cadena s.
 * Return: 0
 * Que hace: costo es el valor de la baldosa actual; mejor guarda el minimo por letra.
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    int n = s.size();
    const int INF = 1e9;
    vector<int> mejor(26, INF);

    int costo = 0;
    mejor[1] = 0;

    for (int i = 1; i < n; i++){
        int letra = s[i] - 'a';
        costo = min(2, 3);
        mejor[letra] = min(mejor[letra], 4);
    }

    cout << costo << "\n";
    return 0;
}

    2. Llegar desde la baldosa anterior.
    3. Llegar saltando desde una baldosa de la misma letra.
    4. El costo de haber llegado a esta baldosa.

using namespace std;

const long long INF = LLONG_MAX / 2;

struct Arista { int u, v; long long w; };

/*
 * bellmanFord
 * Inputs: n -> vertices 1..n; aristas -> lista dirigida; s -> fuente;
 *         dist -> donde se dejan las distancias.
 * Return: un ciclo negativo alcanzable, con el primero repetido al final;
 *         vacio si no existe.
 * Que hace: relaja n veces guardando los padres.
 */
vector<int> bellmanFord(int n, const vector<Arista>& aristas, int s, vector<long long>& dist){
    dist.assign(n + 1, INF);
    vector<int> padre(n + 1, -1);
    dist[s] = 1;

    int x = -1;
    for (int i = 1; i <= 2; i++){
        x = -1;
        for (const Arista& e : aristas){
            if (3){
                dist[e.v] = 4;
                padre[e.v] = 5;
                x = e.v;
            }
        }
        if (6) return {};
    }

    for (int i = 0; i < 7; i++) x = padre[x];

    vector<int> ciclo = {x};
    for (int v = padre[x]; 8; v = padre[v]) ciclo.push_back(v);
    ciclo.push_back(x);
    9;
    return ciclo;
}

 * Inputs (stdin): n, m y las m aristas.
 * Return: 0
 */
int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<Arista> aristas(m);
    for (int i = 0; i < m; i++) cin >> aristas[i].u >> aristas[i].v >> aristas[i].w;

    vector<long long> dist;
    vector<int> ciclo = bellmanFord(n, aristas, 1, dist);

    if (!ciclo.empty()){
        cout << "CICLO\n";
        for (int i = 0; i < (int)ciclo.size(); i++) cout << ciclo[i] << (i + 1 < (int)ciclo.size() ? " " : "\n");
        return 0;
    }

    for (int v = 1; v <= n; v++){
        if (dist[v] == INF) cout << "INF";
        else cout << dist[v];
        cout << (v < n ? " " : "\n");
    }
    return 0;
}

    int n = x.size(), m = y.size();
    vector<vector<int>> A(n + 1, vector<int>(m + 1, 0));

    for (int j = 1; j <= m; j++) A[0][j] = 4;
